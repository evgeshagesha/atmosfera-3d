# 🔐 Доступ к серверу — как работать со мной безопасно

> Для новичка. Без жаргона. **Пароли в чат не кидаем.**

---

## 📋 Главное правило

**Я не «захожу на сервер» как человек.** Я работаю с **файлами в проекте** на твоём Mac.  
Ты переносишь файлы **с сервера → в проект** или **из проекта → на сервер**.

Так безопаснее: секреты не попадают в GitHub и в переписку.

---

## 🏗 Схема работы (простая)

```
Tilda / сервер                    Проект Cursor                    Сервер eg.egoshev.ru
     │                                  │                                  │
     │  ① скачать файлы                 │                                  │
     └──────────────────────────────► 01_ПРОЕКТЫ/P01/site/               │
                                        │                                  │
                                        │  ② я правлю HTML/CSS/JS          │
                                        │                                  │
                                        │  ③ ты заливаешь обратно          │
                                        └─────────────────────────────────►│
```

**Итог:** мне не нужен пароль от сервера, если файлы лежат в папке проекта.

## ✅ Что сделать тебе (по шагам)

### Шаг 1 · Поддомен на сервере

В панели хостинга (Beget или другой):

1. Создай поддомен **`eg.egoshev.ru`**
2. Папка сайта — обычно что-то вроде:
   - `~/eg.egoshev.ru/public_html`
   - или `/home/логин/eg.egoshev.ru/public_html`
3. Включи **SSL** (Let's Encrypt) для `eg.egoshev.ru`
4. DNS: запись **A** `eg` → IP сервера (если ещё не настроено)

### Шаг 2 · Перенеси файлы с Tilda на сервер

Как ты уже делаешь — экспорт HTML / заливка через FTP или файловый менеджер.

### Шаг 3 · Скопируй файлы в проект (это и есть «доступ» для меня)

**Вариант А — через панель Beget:**  
Скачай папку `public_html` поддомена → положи в:

```
~/Projects/atmosfera-3d/01_ПРОЕКТЫ/P01_сайт_и_сервер/site/
```

**Вариант Б — через Terminal** (если есть SSH):

```bash
mkdir -p ~/Projects/atmosfera-3d/01_ПРОЕКТЫ/P01_сайт_и_сервер/site
scp -r ТВОЙ_ЛОГИН@IP_СЕРВЕРА:~/eg.egoshev.ru/public_html/* \
  ~/Projects/atmosfera-3d/01_ПРОЕКТЫ/P01_сайт_и_сервер/site/
```

После копирования напиши: **«файлы сайта в проекте»** — я смогу править.

### Шаг 4 · Создай файл доступов (локально, не в GitHub)

```bash
cp ~/Projects/atmosfera-3d/01_ПРОЕКТЫ/P01_сайт_и_сервер/.env.example \
   ~/Projects/atmosfera-3d/01_ПРОЕКТЫ/P01_сайт_и_сервер/.env
```

Заполни `.env` **у себя на Mac** — он в `.gitignore`, в GitHub не уйдёт.

---

## 🚫 Что НЕ делать

| ❌ Нельзя | Почему |
|---|---|
| Писать пароль SSH/FTP в чат | Утечка, небезопасно |
| Коммитить `.env` в GitHub | Секреты станут публичными |
| Давать root-доступ | Достаточно папки одного сайта |

## 📤 Что мне прислать в чат (безопасно)

Можно писать текстом:

1. **Хостинг:** Beget / другой?
2. **Путь к папке** поддомена на сервере (без пароля)
3. **Список страниц**, которые уже перенесены: `/`, `/baza`, `/club`…
4. **Список правок**, которые нужны (по пунктам)
5. **Ссылка** на тест: https://eg.egoshev.ru/ — работает или ошибка?

Не присылай: пароль, SSH-ключ, токены.

## 🔄 Как заливать правки обратно на сервер

После моих правок в `site/`:

**Через панель:** File Manager → загрузить изменённые файлы.

**Через Terminal:**

```bash
cd ~/Projects/atmosfera-3d/01_ПРОЕКТЫ/P01_сайт_и_сервер/site
scp -r ./* ТВОЙ_ЛОГИН@IP_СЕРВЕРА:~/eg.egoshev.ru/public_html/
```

Или один файл:

```bash
scp index.html ТВОЙ_ЛОГИН@IP:~/eg.egoshev.ru/public_html/
```
