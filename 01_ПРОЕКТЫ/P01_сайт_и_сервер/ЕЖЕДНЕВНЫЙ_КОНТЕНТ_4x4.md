## ⚙️ Что автоматизируемо vs HITL

| Шаг | Авто | HITL |
|---|---|---|
| HEIC→JPG в photo bank | ✅ скрипт / `sips` | проверка кадров |
| Cover с title overlay | ✅ скрипт (PIL) | финальный вкус |
| Запись в `blog.json` + слоты | ✅ по шаблону | голос / факты / approve |
| Deploy site (`rsync` + build + pm2) | ✅ | подтверждение «выложи» |
| VK `wall.post` (клуб / страница) | ⚠️ если есть токен | текст + картинка глазами |
| Yandex Business публикации | ❌ нет стабильного API | pack → браузер |
| Instagram Stories | ❌ | pack frames → телефон / Meta |
| Telegram канал | ⚠️ отдельный контур | не смешивать с blog-day без флага |
