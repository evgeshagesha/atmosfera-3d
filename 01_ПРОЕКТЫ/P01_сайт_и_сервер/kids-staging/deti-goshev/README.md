# Детские программы движения и характера — Евгений Гошев

Одностраничный статический сайт детского направления. Два формата: **«Лаборатория движения»** (будни) и **«День движения и характера»** (выходные). Без фреймворков и сборщика — чистые HTML, CSS, JS.

---

## 1. Как открыть локально
Дважды кликните `index.html` — страница откроется в браузере.
Для проверки как на реальном сервере (чище работают шрифты и пути) можно запустить локальный сервер из папки проекта:
```
python3 -m http.server 8000
```
и открыть `http://localhost:8000`.

## 2. Где изменить ссылку на анкету
`script.js`, самый верх файла:
```js
const APPLICATION_URL = "ВСТАВИТЬ_ССЫЛКУ_НА_АНКЕТУ";
```
Вставьте реальный адрес анкеты. Все кнопки автоматически подставят к нему параметр формата:
`?format=weekday`, `?format=weekend` или `?format=general`.
Пока ссылка не добавлена, при клике открывается аккуратное модальное окно (не ошибка).

## 3. Где изменить ссылку «Обо мне»
`script.js`, вторая строка:
```js
const ABOUT_URL = "ВСТАВИТЬ_ССЫЛКУ_НА_СТРАНИЦУ_ОБО_МНЕ";
```

## 4. Где изменить цены и параметры форматов — ГЛАВНОЕ
Все цены, длительности и размеры группы хранятся **в одном месте** — объект `PROGRAMS` в `script.js`:
```js
const PROGRAMS = {
  weekday: { price: "15 000 ₽", duration: "1,5–2 часа", ... },
  weekend: { price: "17 000 ₽", duration: "4–5 часов", ... }
};
```
Чтобы поднять цену выходного дня до 20 000 ₽ — правьте только `weekend.price`. Значение само подставится во все карточки, блок стоимости и мобильную кнопку. **В HTML цены вручную не дублируются.**

## 5. Где изменить расписание / программу дня
- Таймлайн будничного занятия — секция `#weekday`, список `.flow-list` в `index.html`.
- Таймлайн выходного дня (4–5 ч) — секция `#weekend`, список `.timeline` в `index.html`.
- Времена в выходном дне указаны относительно старта (00:00 = начало программы).

## 6. Где заменить фотографии
Сейчас на месте фото стоят заглушки `.photo-placeholder` со служебной подписью — что за кадр нужен.
Чтобы вставить реальное фото, замените блок заглушки на `<img>`:
```html
<img src="assets/images/eugene-kids-hero.webp"
     alt="Евгений Гошев проводит занятие"
     class="photo-placeholder--hero" loading="lazy">
```
Для первого экрана `loading="lazy"` не ставьте (это главный кадр).

## 7. Названия файлов фотографий (положить в `assets/images/`)
**Будни (Лаборатория движения):**
- `weekday-foot-work.webp` — крупный план работы со стопой и опорой
- `weekday-crawl.webp` — ребёнок ползёт / естественное движение
- `weekday-balance.webp` — упражнение на баланс и координацию
- `weekday-coaching.webp` — Евгений спокойно объясняет задание
- `weekday-studio.webp` — общий кадр студии

**Выходные (День движения и характера):**
- `weekend-movement.webp` — общая тренировка в группе до 4 детей
- `weekend-walk.webp` — прогулка в парке или лесу
- `weekend-meal.webp` — совместный приём пищи
- `weekend-film.webp` — просмотр истории/фильма (без крупных планов детских лиц)
- `weekend-discussion.webp` — обсуждение с Евгением
- `weekend-team-task.webp` — командное задание

**Общие:**
- `eugene-kids-hero.webp` — Евгений в студии или на природе (первый экран)
- `eugene-portrait.webp` — профессиональный портрет
- `studio-savelovskaya.webp` — интерьер студии
- `og-image.webp` — картинка для соцсетей, 1200×630

## 8. Рекомендуемые размеры и формат
- Формат: **WebP** (запасной JPEG допустим).
- Первый экран / портрет (вертикальные 4:5): ~1200×1500 px.
- Локации / широкие кадры (16:11–16:10): ~1400×900 px.
- Финальный кадр (16:10): ~1600×1000 px.
- OG-картинка: ровно 1200×630 px.
- Вес каждого файла — по возможности до 250 КБ.
- Съёмка детей — со спины, сбоку или без крупных планов лиц. **Не использовать чужие/стоковые фото детей.**

## 9. Как разместить на сервере
Загрузите всю папку (`index.html`, `styles.css`, `script.js`, `assets/`) в корень домена/поддомена (например `egoshev.ru/kids`). Дополнительная настройка не нужна — сайт статический.

## 10. Куда вставить Яндекс Метрику
В `index.html`, в `<head>`, есть комментарий:
```html
<!-- ВСТАВИТЬ КОД ЯНДЕКС МЕТРИКИ -->
```
Вставьте туда счётчик. Чтобы заработали цели, после инициализации Метрики задайте номер счётчика:
```html
<script>window.YM_COUNTER_ID = 12345678;</script>
```
Тогда события `program_format_selected`, `application_clicked` (с `program_type`), `price_section_viewed`, `location_selected`, `faq_opened` будут отправляться автоматически. Дублируются в `window.dataLayer` (для GTM).

Перед публичным запуском трансфера отдельно проверьте договор, страхование, согласия родителей и требования к перевозке детей (см. комментарий в блоке FAQ).

## 13. Что сейчас является заглушкой
- Все фотографии (`.photo-placeholder`) — с подписью нужного кадра.
- `APPLICATION_URL` и `ABOUT_URL` — плейсхолдеры.
- Ссылки подвала (`#`).
- `favicon.svg` — временный бренд-знак.
- Код Яндекс Метрики.
- Блока отзывов нет намеренно: реальных отзывов об этой программе пока нет, вымышленные не добавлялись.

## 14. Как отключить или изменить секцию
Каждая секция — отдельный `<section>` с `id` (`#formats`, `#pains`, `#why`, `#weekday`, `#weekend`, `#ages`, `#locations`, `#author`, `#four`, `#parents`, `#safety`, `#pricing`, `#faq`, `#final`). Чтобы убрать секцию — удалите её блок и соответствующий пункт в навигации (`.nav` и `.mobile-menu`).

## 15. Как проверить мобильную версию
В браузере: DevTools → режим устройства (Ctrl/Cmd+Shift+M). Проверьте ширины **320 / 360 / 375 / 390 / 414 / 768 / 1024 / 1440 px**. Ожидается: нет горизонтальной прокрутки, карточки форматов идут одна под другой, снизу появляется фиксированная кнопка с ценой выбранного формата, таймлайн вертикальный, FAQ открывается пальцем.
