## Когда соберём бот + Kie.ai (контент)

Каждая статья / страница должна:

1. Один главный ключ + 2–3 смежных (не «про всё сразу»).
2. H1 = смысл запроса, без кликбейта и медобещаний.
3. В тексте: механизм → что делать → следующий шаг (продукт / анкета / студия).
4. Внутренние ссылки: тест 684 → дыхание 1990 → база 9990 → клуб 1680.
5. Schema `Article` + автор «Евгений Гошев».
6. Гео: Москва / онлайн, без спама.
