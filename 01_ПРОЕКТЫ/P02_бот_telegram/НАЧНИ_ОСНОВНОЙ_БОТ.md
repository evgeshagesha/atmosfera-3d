## Чем бот вам поможет (карта ролей)

| Где | Что делает бот | Что не делает |
|---|---|---|
| **Личка** | ТЕЛО → гайд · тест · PDF Level 1/2/3 · кнопки 1990/9990/клуб | Не «лечит» и не ставит диагнозы |
| **Канал** `@EvgeniiGoshev` | Черновик поста → вы OK → публикация | Не постит без вашего OK |
| **Группа клуба** | Приветствие · ссылки · позже доступ по подписке | Не сыплет PDF всем подряд |
| **Блог сайта** | Позже: черновик статьи → вы OK → публикация | Не автопубликация без approve |
| **Вы + Cursor** | Правки кода, тексты, деплой | Секреты только в `.env` у вас |

> 💡 PDF уровней — **только в личку**. Группа = сообщество, не склад файлов.

## Старт: 4 шага (сегодня)

### Шаг 1 — создать бота (вы, 5 минут)

1. Откройте Telegram → [@BotFather](https://t.me/BotFather)
2. `/newbot` → имя, например: `Атмосфера 3D`  
3. Username, например: `atmosfera3d_bot` (должен быть свободен)
4. Скопируйте **токен** (длинная строка) — **не в чат Cursor**
5. По желанию: `/setdescription`, `/setuserpic`

Напишите мне в чат только: **«бот создан, username @….»** (без токена).

### Шаг 2 — секреты локально (вы)

Откройте в Cursor файл:

`01_ПРОЕКТЫ/P02_бот_telegram/bot/.env`

Вставьте (токен не показывайте мне):

```
TELEGRAM_BOT_TOKEN=ваш_токен
CHANNEL_ID=@EvgeniiGoshev
ADMIN_TELEGRAM_IDS=ваш_числовой_id
```

Свой numeric ID: напишите боту [@userinfobot](https://t.me/userinfobot) → он ответит цифрой.

Когда готово — в чат только: **«секреты в .env»**.

### Шаг 3 — права в Telegram (вы)

| Куда | Право |
|---|---|
| Канал `@EvgeniiGoshev` | Бот = админ, «публикация сообщений» |
| Группа клуба | Бот = админ (можно без права удалять всех) |
| Меню бота (BotFather → Menu Button) | пока `https://egoshev.ru/testik` или `/menu` |

ID группы (для `.env` → `COMMUNITY_CHAT_ID`): добавьте бота в группу → перешлите любое сообщение группы боту [@getidsbot](https://t.me/getidsbot) или смотрите через API позже вместе.

### Шаг 4 — выкладка на сервер (мы вместе)

Когда шаги 1–2 готовы, напишите: **«деплоим бота»**.

Я по инструкции залью код на Timeweb, подниму сервис, проверим `/start`.

## Порядок функций (после основы)

| № | Функция | Когда |
|---|---|---|
| 1 | `/start` · `/start telo` · гайд · `/test` | сразу после деплоя |
| 2 | PDF Level 1/2/3 в личку | день 1–2 после основы |
| 3 | Кнопки 1990 / 9990 / клуб | сразу после PDF |
| 4 | Черновики постов канала + ваш OK | дни 3–5 |
| 5 | Блог: черновик → approve → publish | после стабильного канала |
| 6 | Webhook оплат Prodamus | когда бот уже отвечает |

## Что принести мне (без секретов)

- [ ] Username бота `@…`
- [ ] «секреты в .env»
- [ ] Есть ли Level 2.pdf и Level 3.pdf (или пока только Level 1)
- [ ] Username/название группы клуба
- [ ] Когда будете готовы: «деплоим бота»

> 💡 PDF уровней лежат в `bot/assets/levels/level_1.pdf` … `level_3.pdf`.  
> Команды: `/level1` `/level2` `/level3` или `/levelscore 42`.  
> На Tilda кнопки level1/2/3 лучше вести в бота: `t.me/БОТ?start=level1` и т.д.
