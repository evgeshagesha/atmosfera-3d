# 📂 Где лежит .env (секреты бота)

Файл **уже создан**. Он **скрытый** (имя начинается с точки) — в Finder его не видно по умолчанию.

## Путь

```
01_ПРОЕКТЫ/P02_бот_telegram/bot/.env
```

## Как открыть в Cursor

1. В левой панели открой папки: `01_ПРОЕКТЫ` → `P02_бот_telegram` → `bot`
2. Нажми **Cmd + Shift + .** (точка) в Finder — покажет скрытые файлы  
   **Или** в Cursor: **Cmd + P** и набери: `.env`
3. Открой файл `.env` и вставь токены **после знака =**

Пример (токен не присылай в чат):

```
TELEGRAM_BOT_TOKEN=сюда_токен_от_BotFather
ADMIN_TELEGRAM_IDS=твой_числовой_id
PRODAMUS_SECRET=
```

Когда заполнишь — напиши в чат только: **«секреты в .env»**.

Рядом лежит шаблон `.env.example` (без секретов) — его можно смотреть как образец.
