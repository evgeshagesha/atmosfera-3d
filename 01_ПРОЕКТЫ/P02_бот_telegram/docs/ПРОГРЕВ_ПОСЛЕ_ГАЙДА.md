# 📬 Прогрев после гайда — простыми словами

> Что происходит с человеком после слова ТЕЛО / `/start telo`.

## Путь человека (как дверь в студию)

```
1. Человек пишет боту (Instagram → ТЕЛО или /start telo)
2. Бот: «Подпишись на канал» → кнопки
3. Человек подписался → «Я подписался — открыть гайд»
4. Бот сразу выдаёт гайд (кнопка PDF) и говорит: «пришлю ещё несколько подсказок»
5. Дальше — короткие сообщения по расписанию (прогрев)
```

## 5 сообщений прогрева (как у сильных ботов, но в тоне EG)

| Когда | Зачем | Продажа? |
|-------|--------|----------|
| Через **2 часа** | Напомнить: сделай один блок из гайда + канал | Нет |
| Через **1 сутки** | Вопрос / мягкий контакт | Нет |
| Через **2 суток** | Тест тела 684 ₽ | Мягко |
| Через **4 дня** | Курс «Базовая настройка» **9 990 ₽** | Да, спокойно |
| Через **7 дней** | Клуб **1 758 ₽** + «можно просто остаться в канале» | Да, без давления |

Правила сильных воронок, которые мы взяли:

- ценность раньше продажи;
- не чаще, чем раз в сутки (после первого короткого касания);
- одна кнопка / одна идея в сообщении;
- без крика и «купи сейчас или умри».

## Как проверить тебе

1. Напиши боту `/start telo` (или слово ТЕЛО).
2. Пройди подписку → получи гайд.
3. В логах сервера должно быть: `Scheduled 5 lead follow-ups`.
4. Через 2 часа — первое сообщение (или попроси меня сократить таймеры для теста).
