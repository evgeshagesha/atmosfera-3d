# АТМОСФЕРА 3D — OS для Cursor

Единая система бренда, контента, продуктов и запусков Евгения Гошева.
Отсюда Cursor берёт правду: кто я, как звучу, что и почём продаю, как строю страницы и контент.

## Как это устроено (и почему так)

- **AGENTS.md** (корень) — главный портативный контекст. Его Cursor читает автоматически. Это и есть «бренд-бук в одном файле».
- **.cursor/rules/*.mdc** — короткие правила, которые Cursor подгружает по ситуации (по типу файла или по запросу). Формат `.mdc` = markdown + YAML-шапка (`description`, `globs`, `alwaysApply`). Обычный `.md` в этой папке Cursor игнорирует — только `.mdc`.
- **brand/** — дизайн-токены и CSS для страниц и документов.
- **agents/** — промпты суб-агентов: Reels, YouTube, прогрев, бриф видеомонтажёру, «очеловечиватель» текста.
- **plan/** — дорожная карта к 1 000 000 ₽/мес.
- **programs/** — правила и каркас клиентских программ и документов «после сессии».

## Как запустить в Cursor

1. Открой эту папку как проект в Cursor (File → Open Folder).
2. Cursor сам подхватит `AGENTS.md` и `.cursor/rules/`. Проверь: Settings → Rules — правила должны быть видны.
3. Правила `alwaysApply: true` действуют всегда. Остальные — когда открываешь `.html/.css` (дизайн) или просишь контент (агенты подтянутся по запросу).
4. Для агентов пиши задачу простым языком: «сделай 10 хуков для женской аудитории про осанку» — Cursor возьмёт правила голоса + агента Reels.

## Честные заметки (прочитай)

- **HeyGen-аватар.** Cursor его не создаёт. Он помогает с пайплайном: сценарий → текст под озвучку → загрузка в HeyGen → сборка. Аватар — только под теорию/«говорящую голову», не под демонстрацию движения. См. `agents/avatar-pipeline.md`.
- **«Человеческий голос».** Нет плагина, который делает это магически. Рабочая схема: твой черновик/голосовая → лёгкая редактура по правилам голоса → проверка на ИИ-маркеры. См. `agents/humanizer.md`.
- **Плагины/MCP.** Реально полезное подключается через MCP (например, Notion уже подключён). Не через «скачать плагин с GitHub». Список того, что стоит подключить — в `plan/roadmap-1M.md`, блок «Инструменты».
- **ЦЕНЫ И ССЫЛКИ РАСХОДЯТСЯ в твоих документах** (тест 490 vs 684; клуб 4990 навсегда vs 1990/мес; челлендж 2990). Я поставил в `.cursor/rules/20-products-prices.mdc` последние значения и пометил спорные как `[ПОДТВЕРДИ]`. Зафиксируй ОДНУ версию — это сейчас единственный источник правды для всей системы.
