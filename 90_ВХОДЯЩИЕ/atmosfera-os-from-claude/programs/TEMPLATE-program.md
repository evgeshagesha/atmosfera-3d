# Шаблон клиентской программы / документа «после сессии»

Наследует `.cursor/rules/50-programs.mdc`. Эталоны в проекте Claude: Марина, Денис Бурлаков, Михаил;
канон — Даниил Месяц-1. Рендер: HTML → PDF, тёмный люкс, Manrope, токены из `brand/design-tokens.css`.

## Структура
1. **Обложка** — имя клиента, «Атмосфера 3D · движение · дыхание · дисциплина», t.me/EGoshev.
2. **Оценка** — что увидели (нейтрально, «тело адаптировалось», без диагнозов).
3. **Карта тела** — зоны и связи (стопа → таз → кор → грудной → лопатки → дыхание → походка).
4. **Механизм** — почему так, с пояснением каждого термина.
5. **Протоколы**:
   - МФР (фиксация точки → активное укорочение↔удлинение → ~2 мин → дальше по мышце).
   - Дыхание (длинный выдох 4–6; двойной вдох — длинный выдох; дыхание в нижние рёбра).
   - Упражнения со ссылками на видео (t.me/egoshevuprazhneniya).
6. **Восстановление / быт** — сон, вода, тёплые солевые ванны, холод мягко и позже.
7. **Анализы** (по желанию) — базовая панель; приём добавок только через врача клиента.
8. **Маркеры прогресса** — по чему поймём, что двигаемся.
9. **Блок услуг (4 оффера)** — план 15 000 (герой) + курс 9 990 + клуб + студия.
10. **Отзыв Яндекс.Карты** + ссылки в подвале (egoshev.ru/tree) + дисклеймер.

## Рамки
- Клиническая точность важнее красоты. Реальная биомеханика, не упрощение ради истории.
- Безопасность: «если что-то отзывается болью — снизь нагрузку и напиши мне».
- Не просить у клиента видео себя. Без медицинских обещаний.
- «не X, а Y» — почти не использовать в клиентском тексте.

## Тренировочная неделя (модель проф. спортсмена)
Сила не каждый день. Микс: сила + кардио + Animal Flow + ежедневная мобильность + день
восстановления (МФР) + закаливание/вода + гидратация. Больше Animal Flow и стабильности, меньше
тяжёлой силы. В приседах/силовой следить за большими пальцами стоп (резинка на пальцы). В Animal
Flow — loaded beast kickthrough. В full body: грудная мобильность, односторонние тяги, интеграция.
