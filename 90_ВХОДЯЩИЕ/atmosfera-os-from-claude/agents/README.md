# Агентская система «Атмосфера 3D»

Это не про «нанять людей». Это набор ролей-промптов, которые Cursor берёт под конкретную задачу.
Все они наследуют `AGENTS.md` + правила голоса и продуктов. Ты вызываешь их простым языком.

## Оркестратор (главный агент = сам Cursor)
Понимает задачу → выбирает нужного суб-агента → применяет правила голоса и продуктов → отдаёт
результат в нужном формате. Всегда сначала черновик, потом уточнения. Не задаёт несколько
вопросов подряд.

## Суб-агенты
| Файл | Роль | Когда звать |
|---|---|---|
| `reels-agent.md` | Сценарии Reels/Shorts + хуки | «сделай рилс / 20 хуков про …» |
| `youtube-agent.md` | Сценарии длинных видео + заголовки + нарезки | «сценарий на ютуб про …» |
| `warmup-agent.md` | Прогрев и запуск (7-дневная серия) | «собери прогрев к запуску …» |
| `sales-agent.md` | Продающие тексты, директ-скрипты, дожим | «напиши оффер / ответ в директ …» |
| `editor-brief.md` | Бриф видеомонтажёру (Андрей) | «сделай бриф на монтаж …» |
| `humanizer.md` | Редактура под живой голос Евгения | «причеши мою голосовую / убери ИИ» |
| `avatar-pipeline.md` | Пайплайн HeyGen (только теория) | «сделай текст под аватар …» |

## Как звать в Cursor
Просто пиши задачу. При желании явно: «используй reels-agent, аудитория — женщины, тема — осанка».
Каждый суб-агент на выходе даёт: **вариант(ы) + под какой сегмент + функция (охват/доверие/
продажа) + куда ведёт в лестнице + CTA.**

## Сегменты (передавай агенту)
женщины (осанка/ягодицы/биомеханика) · мужчины (функциональная сила без зала) · дети (Kids).
Метод один, меняются боль, слова, обложка.
