# Журнал решений (Атмосфера 3D OS)

Единый список: что зафиксировано, что открыто. Cursor: при конфликте — правда здесь.
Обновляется по мере решений Евгения.

## Зафиксировано
- **Клуб — рекуррентная подписка** (не «навсегда»). Клуб = главный пассивный движок / MRR.
  Ориентир цены 1 758 ₽/мес.
- **Все тренировки без зала**: Animal Flow, Functional Patterns, гири, функциональные, дыхательные.
- **Сегменты**: женщины (осанка/ягодицы/биомеханика), мужчины (сила без зала), дети (Kids).
  Метод один, меняются боль/слова/обложка.
- **Приоритет задач для Cursor**: «то, что скажет Евгений» — система гибкая, исполняет любую задачу
  по правилам. Фиксированного первого продукта нет.
- **Доступ Cursor**: локальный репозиторий сайта. Стек неизвестен → Cursor сначала анализирует репо.
- **Голос**: тёплый, спокойный, экспертный; запрещённые слова и анти-ИИ-маркеры — см. правило голоса.
- **Аутро везде**: «Атмосфера 3D. Движение. Дыхание. Дисциплина.»

## Открыто (решим позже — стоит дефолт)
- **Цена теста**: дефолт 490 ₽ (трипвайер). Евгений думает поднять — совет держать 490–690.
- **Цена клуба**: 1 758 ₽/мес ориентир; альтернативы по системе Евгения 1 680 / 1 860.
- **Шрифт заголовков**: дефолт Montserrat ExtraBold (бесплатный); варианты Magistral / Benzin — по лицензии.
- **Цена челленджа «21 день»**: ~2 990 ₽, первый можно дешевле/бесплатно ради базы и кейсов.
- **Ссылка на отзыв Яндекс.Карты**: две версии в документах (CPwkRCzS / CTu240~o) — вставить актуальную.
- **HeyGen-аватар**: после выхода на стабильную выручку; только под теорию, не под движение.

## Техника под рекуррент (проверить перед запуском клуба)
Автосписание Prodamus · авто-добавление/удаление из клуба при оплате/неоплате · единый ID клиента ·
синхронизация статусов · уведомления о продлении · резервная ручная выдача. Один продукт = свой
ресивер в Tilda Members (смешение ресиверов открывает доступ ко всему — критический риск).
