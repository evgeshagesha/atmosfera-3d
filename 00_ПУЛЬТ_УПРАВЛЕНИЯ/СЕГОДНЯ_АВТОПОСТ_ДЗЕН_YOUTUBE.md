## 3. Автопостинг блога → VK (+ опционально TG)

Уже есть скрипт: `publish_blog_social.py`  
Инструкция: [VK_ПОДКЛЮЧЕНИЕ_ПОСТИНГ.md](./VK_ПОДКЛЮЧЕНИЕ_ПОСТИНГ.md) · [АВТОПОСТ_БЛОГ_VK_TELEGRAM.md](./АВТОПОСТ_БЛОГ_VK_TELEGRAM.md)

### Режим EG (правильный)

```text
Статья на сайте (одобрена)
→ команда publish_blog_social.py --slug … --vk --short
→ стена VK
```

Полный cron «сам всё постит без OK» — **после** первой успешной ручной публикации.

### Что нужно от Евгения

1. ID сообщества VK (`VK_GROUP_ID`) — можно прислать в чат.  
2. Ключ API с правами **стена + фото** — **только в `.env` на сервере**, не в чат.  
3. Написать: «VK готово» → Agent проверит dry-run и тестовый пост.

### На сервере (когда ключ есть)

```bash
# в /opt/atmosfera-bot/.env
VK_ACCESS_TOKEN=...
VK_GROUP_ID=...
BLOG_JSON_PATH=/var/www/egoshev.ru/data/blog.json   # актуальный путь на VPS

# проверка
cd /opt/atmosfera-bot && ./venv/bin/python publish_blog_social.py --slug <slug> --dry-run --vk --short

# публикация
./venv/bin/python publish_blog_social.py --slug <slug> --vk --short
```

**Отдельно:** мост Telegram→VK (`VK_BRIDGE`) — для текста/фото канала, **не** для YouTube-видео и не замена blog publisher.

## 4. Подключить сайт к Яндекс Дзен

RSS уже живой: **https://eg.egoshev.ru/rss.xml**

### Шаги в Дзен (кабинет автора)

1. Зайти в [Яндекс Дзен](https://dzen.ru) → свой канал / создать.  
2. Настройки → **Публикации / RSS / Импорт** (формулировка в кабинете может чуть отличаться).  
3. Указать ленту: `https://eg.egoshev.ru/rss.xml`  
4. Дождаться модерации / первой синхронизации.  
5. Проверить, что карточки статей открываются на `eg.egoshev.ru/blog/...`

### Важно

- Источник контента для Дзена = **блог Next** (`eg.egoshev.ru`), не Tilda-курсы.  
- Не дублировать full-text чужих новостей — только свои статьи EG.  
- Если Дзен просит `egoshev.ru` вместо `eg.` — после cutover DNS поменять URL ленты; сейчас рабочий RSS на `eg.`.

### Если в кабинете нет пункта RSS

Варианты: «Свой сайт» / «Импорт из RSS» / поддержка Дзена. Агент не логинится в твой Дзен — шаги делаешь ты, при скрине ошибки разберём.
