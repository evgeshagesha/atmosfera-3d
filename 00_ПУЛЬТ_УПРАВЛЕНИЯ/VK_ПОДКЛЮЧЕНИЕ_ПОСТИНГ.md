| | |
|--|--|

## Шаг 1. Открой своё сообщество VK

1. Зайди во ВКонтакте под своим аккаунтом
2. Открой сообщество бренда (то, куда хочешь постить)
3. Ты должен быть **администратором** / создателем

---

## Шаг 2. Где взять ID сообщества (`VK_GROUP_ID`)

Нужно **число**, например `123456789` — **без минуса**.

### Способ А (самый простой)
1. Открой сообщество
2. Посмотри адрес в браузере:
   - если `https://vk.com/club123456789` → ID = `123456789`
   - если `https://vk.com/public123456789` → ID = `123456789`
3. Если адрес красивый (`vk.com/atmosfera3d`):
   - Управление → **Настройки** → **Основная информация** / адрес
   - или открой любую запись на стене → в ссылке часто есть `wall-123456789_...`  
     число после `wall-` (до `_`) и есть ID: `123456789`

### Способ Б
1. Открой https://regvk.com/id/ (или аналог «узнать id vk»)
2. Вставь ссылку на сообщество
3. Скопируй **ID группы**

Запиши: `VK_GROUP_ID=........`

---

## Шаг 3. Создать ключ доступа (`VK_ACCESS_TOKEN`)

1. В сообществе: **Управление**
2. **Настройки**
3. Раздел **Работа с API** (иногда «API» / «Ключи доступа»)
4. **Создать ключ**
5. Включи права минимум:
   - ✅ **Стена** (`wall`) — публикация постов
   - ✅ **Фотографии** (`photos`) — обложка к посту
   - ✅ **Доступ в любое время** / `offline` — если есть галочка
6. Подтверди (может попросить код из SMS / VK)
7. Скопируй длинный ключ (`vk1.a....` или похожий)

⚠️ Ключ **не кидай в чат и не в git**. Только в `.env` на сервере.

---

## Шаг 4. Вписать на сервер Timeweb

Напиши мне:  
«VK готово» + **только ID** (токен сам в чат не присылай).

Или сам по SSH:

```bash
ssh egoshev-timeweb
nano /opt/atmosfera-bot/.env
```

Добавь строки:

```env
VK_GROUP_ID=123456789
VK_ACCESS_TOKEN=сюда_твой_ключ
BLOG_JSON_PATH=/var/www/egoshev.ru/data/blog.json
SITE_BLOG_BASE=https://eg.egoshev.ru/blog
SITE_URL_PUBLIC=https://eg.egoshev.ru
```

Сохрани → проверка:

```bash
cd /opt/atmosfera-bot
python3 publish_blog_social.py \
  --slug chto-pokazyvayut-issledovaniya-ob-uglevodah-i-zhirah \
  --dry-run --short
```

Публикация на стену VK:

```bash
python3 publish_blog_social.py \
  --slug chto-pokazyvayut-issledovaniya-ob-uglevodah-i-zhirah \
  --vk --short
```

## Шаг 5. Если ошибка

| Ошибка | Что сделать |
|--------|-------------|
| `Access denied` / нет прав | Пересоздай ключ с `wall` + `photos` |
| `Group auth` | Ключ должен быть **сообщества**, не личного пользователя (или нужен user-token с нужными правами — мы используем community token) |
| Пост без картинки | Проверь путь обложки в статье и права `photos` |
| Не тот ID | В `wall-XXXX_YY` число XXXX — это и есть group id |

---

## Шаг 6. После первой удачной публикации

Можно постить любую статью:

```bash
python3 publish_blog_social.py --slug <slug-статьи> --vk --short
```

Опционально сразу в Telegram-группу:

```bash
python3 publish_blog_social.py --slug <slug> --telegram --vk --short
```
