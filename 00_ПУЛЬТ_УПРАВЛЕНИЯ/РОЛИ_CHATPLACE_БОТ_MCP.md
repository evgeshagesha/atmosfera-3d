## 📋 Кто за что

| Слой | Где живёт | Задача | Что НЕ делает |
|---|---|---|---|
| **ChatPlace** | Instagram | Слово ТЕЛО → ссылка на бота | Не выдаёт гайд сам, не отвечает в Telegram |
| **Бот `@EGoshev_bot`** | Timeweb `/opt/atmosfera-bot` | Гайд, канал, тест, уровни, оплаты 24/7 | Не правит посты канала «от себя» без скрипта |
| **Cursor + MCP** | Твой Mac / Cursor | Правки, черновики, правка навигации, деплой по команде | Не автоотвечает клиентам в Instagram и не заменяет сервер-бот |
| **Mini App** | WebApp → `https://eg.egoshev.ru/...` | Меню/каталог внутри Telegram | Не заменяет оплату Members/Tribute |

## Схема

```
Instagram (ТЕЛО)
    → ChatPlace (только ссылка на бота)
        → @EGoshev_bot на сервере (гайд + воронка)
            → канал @EvgeniiGoshev
                → Mini App / ссылки на eg.egoshev.ru
                    → тест / курсы / клуб (оплата)

Cursor + MCP Telegram
    → помогает ТЕБЕ править канал/навигацию/черновики
    → НЕ стоит в очереди ответов клиентам
```

---

## Перекрывают ли друг друга?

**Нет**, если соблюдать границы:

1. ChatPlace **не** шлёт полный гайд и **не** дублирует кнопки оплаты — только вход в бота.  
2. Сервер-бот — **единственный** автоответчик в Telegram для клиентов.  
3. MCP — только когда **ты** просишь в Cursor («обнови навигацию», «черновик поста»).  
4. Не включать второй бот в те же лички, что `@EGoshev_bot`.  
5. Автопост в канал без твоего OK — запрещён (и через MCP тоже).

## MCP Telegram · что нужно от тебя

Уже настроено в Cursor два сервера:

1. **`telegram`** — Bot API (публикация/пин от бота MCP)  
2. **`telegram-account`** — твой аккаунт (чтение/правка постов как человек)

**Что дать / проверить:**

| Нужно | Зачем |
|---|---|
| Авторизация MCP в Cursor (кнопка Auth / логин) | Иначе «disconnected» |
| Для account: код из Telegram / сессия Telethon | Один раз |
| Бот MCP = админ канала (пост) | Чтобы слать/пинить |
| **Не** класть токены в чат | Только в `~/.cursor/mcp.json` / env |

Скажи в чате: **«подключи Telegram MCP»** или **«обнови пост 1123»** — после Auth я смогу править.

> ⚠️ Если в MCP сидит **другой** bot token, чем `@EGoshev_bot` — это нормально: MCP-бот = руки для канала; сервер-бот = продажи. Главное — не пускать оба в одни и те же автоответы в личку.
