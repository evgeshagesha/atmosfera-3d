## Как вставить каталог в закреп

### Канал @EvgeniiGoshev (сообщение /1123)

1. Открой закреп → **Изменить**
2. В блок «НАЧНИ ОТСЮДА» вставь:

```
📱 Каталог в Telegram (Mini App)
https://t.me/EGoshev_bot?startapp
```

3. Сохрани. Видео не трогай.

> Если `?startapp` открывает не Mini App — в @BotFather → Configure Mini App → URL `https://eg.egoshev.ru/app`

### Группа (клуб / сообщество)

1. Напиши в группу сообщение, например:

```
📱 Каталог программ Атмосфера 3D
Открыть в Telegram:
https://t.me/EGoshev_bot?startapp

Или в браузере:
https://eg.egoshev.ru/app
```

2. Нажми на сообщение → **Закрепить** (Pin) → «Закрепить для всех»
3. Чтобы бот мог закреплять сам — добавь @EGoshev_bot админом с правом Pin messages
