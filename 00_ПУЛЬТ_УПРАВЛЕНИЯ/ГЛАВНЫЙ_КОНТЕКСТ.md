| Старый код (база) | `_АВТОМАТИЗАЦИИ_СТАРЫЕ/telegram_бот/` — Prodamus, курсы, группа уже есть |
| Решение | **Не с нуля** — доработать существующий код под новую задачу |

**Новый бот должен:**
1. Принимать оплату (курс 9 990 + клуб 1 680/мес)
2. Вести воронку (ТЕЛО → прогрев → VSL → покупка)
3. Управлять клубом (доступ, продление, отключение)
4. Автопостинг в Telegram-канал
5. 🔶 Автопостинг на сайт — отдельная сложность (Tilda ограничена, см. ТЗ)
