# 🐙 GitHub — первый раз (для новичка)

> Простая инструкция. Без жаргона. 10 минут.

---

## 📋 Зачем это нужно

GitHub — это **облако для твоих файлов**. Как Google Drive, но для проекта с историей изменений.

| Зачем | Простыми словами |
|---|---|
| Бэкап | Если Mac сломается — всё сохранено |
| Доступ | Откроешь проект на любом компьютере |
| История | Можно вернуться к любой версии |
| Cursor | Я вижу весь проект и работаю с ним |

---

## 🚀 Пошагово (один раз)

### Шаг 1 · Открой Терминал
**Cmd + Пробел** → напиши `Terminal` → Enter

### Шаг 2 · Запусти скрипт
Скопируй и вставь:

```bash
bash ~/Projects/atmosfera-3d/scripts/первый_push_github.sh
```

Скрипт создаст git и первый коммит.

### Шаг 3 · Создай репозиторий на GitHub

1. Открой в браузере: **https://github.com/new**
2. **Repository name:** `atmosfera-3d`
3. **Private** — включи (рекомендую, там бизнес)
4. **НЕ** ставь галочки README, .gitignore, license
5. Нажми **Create repository**

### Шаг 4 · Загрузи файлы

GitHub покажет команды. Выполни в Терминале (замени `ТВОЙ_ЛОГИН`):

```bash
cd ~/Projects/atmosfera-3d
git remote add origin https://github.com/ТВОЙ_ЛОГИН/atmosfera-3d.git
git push -u origin main
```

GitHub спросит логин и пароль. **Пароль — это не обычный пароль**, а **Personal Access Token**:
- GitHub → Settings → Developer settings → Personal access tokens → Generate new token
- Поставь галочку `repo`
- Скопируй токен и вставь вместо пароля

### Шаг 5 · Проверь
Открой `https://github.com/ТВОЙ_ЛОГИН/atmosfera-3d` — там должны быть все файлы.

## ⚠️ Что НЕ попадёт в GitHub (и это правильно)

- Видео из папки `МЕДИА/` (слишком большие)
- Секреты `.env` (ключи бота, Prodamus)
- Старые автоматизации с ключами

---

## ❓ Если что-то не работает

| Ошибка | Решение |
|---|---|
| «Permission denied» на `.git` | Запускай команды в **обычном Терминале Mac**, не через Cursor |
| «Push rejected» | Сначала `git pull`, потом `git push` |
| «Authentication failed» | Используй Token, не пароль от GitHub |
| Не знаю свой логин | Открой github.com — логин в правом верхнем углу |
