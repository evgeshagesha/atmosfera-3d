> 💡 **Локальные заметки:** если нужен личный черновик с паролями — только в `.secrets.local.md` в корне репо (файл в `.gitignore`). Этот файл агент не создаёт и не заполняет. Чеклист ниже — без секретов.

---

## 1. Зачем три секрета

| Секрет | Зачем |
|---|---|
| `PRODAMUS_SECRET` | Подпись webhook Prodamus. Без него оплата не подтверждается (fail-closed), инвайт в клуб не выдаётся. |
| `ADMIN_PASSWORD` | Пароль входа в `/admin` на сайте. Без него логин закрыт. |
| `ADMIN_SECRET` | Отдельный ключ для HMAC-сессии админки. Лучше не совпадать с паролем входа. |

---

## 2. Куда ввести

| Что | Как | Файл на сервере | Переменные | После правки |
|---|---|---|---|---|
| Бот / Prodamus | SSH → Timeweb VPS | `/opt/atmosfera-bot/.env` | `PRODAMUS_SECRET` | `sudo systemctl restart eg-webhook-prodamus` |
| Сайт / админка | SSH → Timeweb VPS | `/var/www/egoshev.ru/.env.production.local` | `ADMIN_PASSWORD`, `ADMIN_SECRET` | restart Next (тот unit/процесс, которым крутится сайт на сервере) |

---

## 3. Откуда взять `PRODAMUS_SECRET`

1. Войти в кабинет **Prodamus**.
2. Открыть настройки **страницы оплаты**.
3. Скопировать **Secret key**.
4. Вставить **только** в `/opt/atmosfera-bot/.env` на сервере (не в чат, не в git).

---

## 4. Как сгенерировать пароли админки

На своём Mac (или на сервере) дважды:

```bash
openssl rand -base64 32
```

- Первый вывод → `ADMIN_PASSWORD`
- Второй вывод → `ADMIN_SECRET`

Сохрани значения у себя (менеджер паролей / `.secrets.local.md`). В репозиторий и в этот чеклист — не копируй.

---

## 5. Шаблон строк для сервера

Плейсхолдеры пустые. Подставь значения **только на сервере** в nano/vim.

**Бот** — `/opt/atmosfera-bot/.env`:

```bash
PRODAMUS_SECRET=<ВСТАВЬ_НА_СЕРВЕРЕ>
```

**Сайт** — `/var/www/egoshev.ru/.env.production.local`:

```bash
ADMIN_PASSWORD=<ВСТАВЬ_НА_СЕРВЕРЕ>
ADMIN_SECRET=<ВСТАВЬ_НА_СЕРВЕРЕ>
```

---

## 6. Чеклист после ввода

- [ ] `PRODAMUS_SECRET` прописан в `/opt/atmosfera-bot/.env`
- [ ] `ADMIN_PASSWORD` и `ADMIN_SECRET` прописаны в `/var/www/egoshev.ru/.env.production.local`
- [ ] `sudo systemctl restart eg-webhook-prodamus`
- [ ] Restart Next (сайт подхватил новый env)
- [ ] Smoke админки: открыть `/admin`, войти своим паролем (успех / отказ без «дыр»)
- [ ] Health webhook: `curl https://bot.egoshev.ru/health` — ответ ок
- [ ] (Опционально) `sudo systemctl status eg-webhook-prodamus` — active

---

## 7. Что сказать агенту после

Когда секреты уже на сервере:

> секреты прописал на Timeweb — деплой код

Агент тогда работает с кодом и деплоем, **не** просит и не читает значения секретов.
