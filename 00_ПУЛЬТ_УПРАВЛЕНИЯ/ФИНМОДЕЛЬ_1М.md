## ⚠️ Риски (говорю прямо)

1. **179 подписчиков клуба** — нужен контент каждую неделю (эфиры, материалы, задания). Иначе отток > приток.
2. **40 курсов без VSL** — маловероятно. VSL — не «красивость», а деньги.
3. **Один человек** — не тянуть 14 Reels/нед + студия + бот + клуб. **1 Reels/день** — потолок реальности.
4. **Автопостинг на Tilda** — Tilda не даёт нормальный API для постов. Сайт = лендинги; контент = Telegram + Instagram.
