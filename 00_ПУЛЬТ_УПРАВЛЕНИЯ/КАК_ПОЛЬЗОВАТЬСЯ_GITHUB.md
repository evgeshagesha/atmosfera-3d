# 🖥 Как пользоваться GitHub

> GitHub — это **облако для твоих файлов и кода**. Туда уходит система (тексты, сайт, бот). Видео и секреты — не туда.

---

## 📋 Свойства

| | |
|---|---|
| **Зачем** | Бэкап + доступ с любого компьютера + история изменений |
| **Твой репозиторий** | 🔶 создадим вместе (например `github.com/evgeshagesha/atmosfera-3d`) |
| **Сложность** | 3 команды — и всё работает |

---

## 🤔 Простыми словами

| Термин | Что это |
|---|---|
| **Репозиторий (repo)** | Папка проекта в облаке |
| **Commit** | Сохранение версии («снимок» изменений) |
| **Push** | Отправить изменения с компьютера в облако |
| **Pull** | Скачать изменения из облака на компьютер |
| **Clone** | Первый раз скачать весь проект к себе |
| **Branch (ветка)** | Параллельная версия (для экспериментов) |

---

## 🚀 Первый раз: загрузить проект в облако

Открой **Терминал** на Mac и выполни по очереди:

```bash
cd ~/Projects/atmosfera-3d
git init
git branch -M main
git add -A
git commit -m "Старт: система Атмосфера 3D"
```

Затем на сайте [github.com](https://github.com) → **New repository** → имя `atmosfera-3d` → Create.

GitHub покажет команды. Пример:

```bash
git remote add origin https://github.com/ТВОЙ_ЛОГИН/atmosfera-3d.git
git push -u origin main
```

> 💡 При первом push GitHub спросит логин и пароль. Используй **Personal Access Token** (не обычный пароль). Создать: GitHub → Settings → Developer settings → Personal access tokens.

---

## 📥 Как скачать проект на другой компьютер

```bash
git clone https://github.com/ТВОЙ_ЛОГИН/atmosfera-3d.git
cd atmosfera-3d
```

Открой эту папку в Cursor — и я уже вижу всю систему.

---

## 🔄 Каждый день: сохранить изменения

После работы со мной:

```bash
cd ~/Projects/atmosfera-3d
git add -A
git commit -m "Кратко: что изменилось"
git push
```

> 💡 **Можешь просто сказать мне:** «закоммить и запушь» — я сделаю, если git настроен.

## 🔌 Плагины и «навыки» — в чём разница

| Что | Где живёт | Зачем |
|---|---|---|
| **Cursor Rules** | `.cursor/rules/` | Я **всегда** знаю твой бренд и правила |
| **Skills (навыки)** | `.cursor/skills/` или `~/.cursor/skills/` | Я **умею** конкретные задачи (контент, продажи) |
| **Agents (агенты)** | `.cursor/agents/` | Отдельные «сотрудники» для разных зон |
| **GitHub Actions** | `.github/workflows/` | Автоматизация на сервере (деплой, бэкапы) |

**Скачать чужой skill:** положи папку с `SKILL.md` в `.cursor/skills/имя-навыка/`. Cursor подхватит автоматически.

> ⚠️ Не клади навыки в `~/.cursor/skills-cursor/` — это служебная папка Cursor.

---

## ❌ Что НЕ кладём в GitHub

- Файлы `.env` (ключи, пароли)
- Видео из папки `МЕДИА/`
- Данные клиентов (`orders.json` и т.п.)

Всё это уже прописано в `.gitignore`.

---

## 🆘 Если что-то сломалось

| Проблема | Решение |
|---|---|
| «Push rejected» | Сначала `git pull`, потом снова `git push` |
| Случайно удалил файл | `git log` → найти commit → `git checkout COMMIT -- путь/к/файлу` |
| Запутался | Напиши мне: «помоги с git» |
