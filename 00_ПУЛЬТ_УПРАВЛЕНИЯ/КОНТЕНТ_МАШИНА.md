## Блог → канал (ежедневно)

**Правило:**
- В **блог** — полная статья + страница на сайте (`eg.egoshev.ru/blog/...`)
- В **канал** — **один раз в день** выжимка: самое важное и интересное из статьи (не копипаст целиком)
- В конце поста канала — **обязательный CTA** в воронку (тест / дыхание / курс / клуб)

```
Статья в блоге (полная)
        ↓
Черновик выжимки для Telegram (коротко, сильно)
        ↓
Ваш OK
        ↓
Пост в @EvgeniiGoshev + CTA
```

Шаблон выжимки:

```
ХУК (1–2 строки)
СУТЬ (что важно знать) — 4–8 предложений
ПОЧЕМУ ЭТО В СИСТЕМЕ EG — 1–2 предложения
CTA → одна ссылка из воронки
ПОЛНЫЙ РАЗБОР → ссылка на статью блога
```

> 💡 Автопост без OK — запрещён. Скрипт может готовить черновик; публикация — только после вашего подтверждения.

## Правило одного CTA

Каждый пост = **одна** цель:

| Тип поста | CTA |
|---|---|
| Охват / механизм | «ТЕЛО» / `/start telo` |
| Доверие / разбор | тест 684 → https://egoshev.ru/testik |
| Дыхание / грудная | https://egoshev.ru/dyhanieosanka |
| Системная настройка | https://egoshev.ru/baza |
| Регулярность | клуб Tribute |
| Proof / кейс | курс / клуб / анкета |

Не смешивать «и курс, и клуб, и студию» в одном посте.
