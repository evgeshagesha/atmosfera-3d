# Структура папок экосистемы EG

Чёткая раскладка: где что лежит и как связано с ботом, Notion и Google.

---

## Корень экосистемы: `eg-ecosystem/`

```
eg-ecosystem/
├── ТЗ_ЭКОСИСТЕМА_EG.md             # Мастер-ТЗ (источник правды)
├── PLAUD_NOTION_АВТОМАТИЗАЦИЯ.md   # Единый контур: аудио → транскрипт → Notion/Drive
├── СТРУКТУРА_ПАПОК_ЭКОСИСТЕМЫ.md   # Этот файл
├── ARCHITECTURE.md                  # Архитектура 3 контуров и потоков данных
├── NOTION_И_PLAUD_НАСТРОЙКА.md     # Поля баз Notion и связь с Plaud
├── knowledge_templates/             # Шаблоны файлов базы знаний (01–12)
│   ├── 01_about_evgeny.md
│   ├── 02_eg_philosophy.md
│   ├── ...
│   └── 12_style_and_tone.md
├── inbox_audio/                     # Единая точка входа: сюда кидаешь все записи (Plaud/диктофон)
├── processed/                       # Обработанные аудио (после транскрипции)
│   ├── clients/<client_slug>/      # По клиентам
│   └── courses/<course_slug>/     # По курсам
├── data/
│   ├── db/                         # SQLite: клиенты, сессии, оценки, курсы
│   ├── transcripts/                # Транскрипты по сессиям и урокам
│   ├── summaries/                  # Summary и выводы по сессиям
│   └── (clients/, wellness_logs/ при необходимости)
├── scripts/                         # Пайплайн: transcribe, process_inbox, sync_notion, sync_drive
└── (docs/ при необходимости)
```

Конвенция имён файлов в `inbox_audio/` и полный пайплайн — в **PLAUD_NOTION_АВТОМАТИЗАЦИЯ.md**.

## Бот (уже есть): `eg-community-bot/`

```
eg-community-bot/
├── bot.py                        # Логика бота (Community + элементы Sales)
├── config.py
├── knowledge_base/               # ← СЮДА класть все знания для бота
│   ├── 00-instrukciya-botu.md
│   ├── 01-tema-i-celi-soobschestva.md
│   ├── ...
│   ├── 04-evolution-go-system.md
│   └── (можно добавить 01_about_evgeny.md и др. из knowledge_templates)
├── data/                         # group_chat_history.json, orders
├── load_knowledge.py             # Загрузка .md/.txt из knowledge_base
├── GOOGLE_SHEETS_SETUP_BOT.md
├── КАК_ЗАГРУЗИТЬ_ЗНАНИЯ_В_БОТА.md
└── deploy/
```

**Важно:** всё, что должен «знать» бот (о тебе, продуктах, философии, ограничениях), лежит в `knowledge_base/`. Файлы из `eg-ecosystem/knowledge_templates/` можно копировать в `knowledge_base/` или переименовывать под свою нумерацию.

---

## Notion (вне Cursor)

- **База «Клиенты»** — карточки, ссылки на Drive, сессии, статусы.
- **База «Сессии»** — каждая встреча: дата, тип, транскрипт, summary, рекомендации.
- **База «Оценка/диагностика»** — зоны тела, шкалы.
- **База «Обучение/курсы»** — твои пройденные курсы, конспекты, транскрипты.
- **База «Протоколы и рекомендации»** — библиотека EG по зонам и протоколам.

---

## Google Drive (вне Cursor)

- **Клиенты/** — папка на каждого (аудио, фото, PDF, МРТ).
- **Курсы/** — материалы обучения, транскрипты уроков.
- **Диагностики/** — файлы оценок.
- **Видео упражнений/, Фото до-после/, PDF-анализы/** — по смыслу.

---

## Как связать

1. **Бот** читает только `eg-community-bot/knowledge_base/` и конфиг (.env, courses_links.json).
2. **ТЗ и шаблоны** в `eg-ecosystem/` — для людей и для копирования в knowledge_base.
3. **Локальные данные** (inbox_audio/, data/, processed/) и **скрипты** (scripts/) — единый контур по документу **PLAUD_NOTION_АВТОМАТИЗАЦИЯ.md**: транскрипция → распределение по клиентам/курсам → синхронизация с Notion/Google при наличии интернета.
4. **История и путь** (документ «История_и_путь_Евгений_Гошев»): экспорт в .md или .txt → положить в `knowledge_base/` (см. КАК_ДОБАВИТЬ_ДОКУМЕНТЫ_В_БОТА.md).
