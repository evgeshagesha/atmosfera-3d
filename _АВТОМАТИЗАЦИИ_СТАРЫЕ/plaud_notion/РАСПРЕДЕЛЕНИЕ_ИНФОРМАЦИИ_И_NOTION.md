## 2. Создание базы в Notion: что нужно

Есть два варианта.

### Вариант A. Notion MCP (чтобы я создавал базы из Cursor)

Чтобы я мог создавать и править базы в Notion прямо из чата, нужен **Notion MCP** в Cursor.

**Что сделать:**

1. **Node.js 18+** — должен быть установлен (проверка в терминале: `node -v`).
2. **Добавить Notion MCP в Cursor:**
   - Открой настройки Cursor → **MCP** (или Features → MCP).
   - Добавь новый MCP-сервер.
   - Укажи:
     - **command:** `npx`
     - **args:** `-y`, `mcp-remote`, `https://mcp.notion.com/mcp`
   - Либо в конфиге MCP (файл `~/.cursor/mcp.json` или через Cursor Settings) добавь запись для Notion по инструкции: https://www.mcpstack.org/use/notion/mcp-server/with/cursor
3. **Авторизация:** при первом использовании Notion MCP откроется OAuth — войди в свой Notion и разреши доступ к workspace. После этого я смогу вызывать инструменты Notion (создание data source/базы, запросы, обновление).
4. **Перезапусти Cursor** после настройки MCP.

Когда Notion MCP будет подключён и авторизован, напиши: «создай в Notion базы по NOTION_И_PLAUD_НАСТРОЙКА» — и я создам базы Клиенты, Сессии, Оценка/диагностика, Обучение/курсы, Протоколы с нужными свойствами (в рамках того, что разрешает API Notion).

**Ограничение:** у меня в текущем списке инструментов Notion MCP может не быть виден, пока ты его не добавишь в настройках Cursor. После добавления сервера и OAuth инструменты Notion появятся, и тогда можно будет создавать базы по запросу.

### Вариант B. Без MCP — скрипт + Notion API

Если MCP не хочешь или не получается подключить:

1. Создай в Notion **интеграцию**: https://www.notion.so/my-integrations → New integration → скопируй **Internal Integration Token**.
2. Создай в Notion **страницу** (или открой существующую), куда будут привязаны базы; открой её и **добавь интеграцию** в настройках страницы (Share → Invite → твоя интеграция).
3. Скажи мне, что готов: я напишу скрипт (Python или Node.js), который по токену и ID родительской страницы создаст в Notion базы с полями из NOTION_И_PLAUD_НАСТРОЙКА.md. Токен ты положишь в `.env` (не в репозиторий).

- **Распределение по папкам:** скидывай любой текст сюда и пиши «распредели по папкам» — разнесу по файлам экосистемы и базы знаний.
- **Базы в Notion:** чтобы я создавал их сам, нужен **Notion MCP** в Cursor (см. вариант A). Иначе — делаешь базы вручную по NOTION_И_PLAUD_НАСТРОЙКА.md или используешь скрипт с API (вариант B).
