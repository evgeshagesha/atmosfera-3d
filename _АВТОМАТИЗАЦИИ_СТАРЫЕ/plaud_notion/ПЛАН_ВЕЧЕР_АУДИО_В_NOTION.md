# План: вечером выгрузил аудио с диктофона — всё само разложилось по папкам и в Notion

Один документ: что сделать один раз, потом что делать каждый вечер.

---

## Часть А. Один раз настроить (потом не трогаешь)

### Шаг 1. Папка на компе

На Mac у тебя есть папка проекта **eg-ecosystem**. В ней уже есть папка **inbox_audio** — это и есть «приёмник»: вечером сюда ты скидываешь все аудио с диктофона (Plaud или любого другого).

Путь примерно такой:  
`/Users/egoshev/eg-ecosystem/inbox_audio`  
(или где у тебя лежит проект eg-ecosystem — внутри него папка **inbox_audio**).

Больше никаких «входных» папок не нужно. Всё, что попадает в **inbox_audio** (или в подпапки внутри неё), скрипт вечером обработает.

---

### Шаг 2. Как сказать системе: это курс или это клиент

Чтобы скрипт понял, куда что класть (в базу «Курсы» или «Клиенты/Сессии» в Notion), нужно **подписать** записи. Самый простой способ — **подпапки** внутри **inbox_audio**:

- Всё, что лежит в папке **inbox_audio/courses/название_курса/** — система считает **уроками этого курса** и потом выгрузит в базу «Обучение/курсы» в Notion.
- Всё, что лежит в папке **inbox_audio/clients/имя_клиента/** — система считает **сессиями этого клиента** и выгрузит в базы «Клиенты» и «Сессии» в Notion.

То есть ты не переименовываешь каждый файл — ты просто кладёшь его в нужную подпапку.

**Пример:**

- Запись урока по курсу «Дыхание» → положи файл в папку:  
  `inbox_audio/courses/дыхание/`  
  (если папки нет — создай: inbox_audio → courses → дыхание).

- Запись консультации клиента Васи → положи файл в папку:  
  `inbox_audio/clients/вася/`  
  (inbox_audio → clients → вася).

Имена самих файлов могут быть любыми (например `запись 1.m4a`, `07.03.m4a`). Важно только **в какой папке** файл лежит.

**Итого по подпапкам:**

| Куда положил файл | Что система сделает |
|-------------------|---------------------|
| inbox_audio/courses/дыхание/ | Урок курса «Дыхание» → Notion «Обучение/курсы» |
| inbox_audio/courses/таз/     | Урок курса «Таз» → Notion «Обучение/курсы» |
| inbox_audio/clients/вася/   | Сессия клиента Вася → Notion «Клиенты» + «Сессии» |
| inbox_audio/clients/мария/  | Сессия клиента Мария → Notion «Клиенты» + «Сессии» |

Папки **courses** и **clients** создай один раз внутри **inbox_audio**. Внутри них — папки по названиям курсов и по именам клиентов. Дальше только кидаешь туда файлы.

---

### Шаг 3. Notion — три базы

В Notion у тебя должны быть три базы (таблицы). Если их ещё нет — создай один раз по описанию в **NOTION_И_PLAUD_НАСТРОЙКА.md** (часть 1):

1. **Клиенты** — таблица с колонкой «Имя» (Title) и др.
2. **Сессии** — таблица с колонками «Клиент» (связь с Клиенты), «Дата», «Тип», «Транскрипт» и др.
3. **Обучение/курсы** — таблица с колонками «Название курса» (Title), «Модуль», «Урок», «Транскрипт» и др.

Скрипт будет создавать в этих базах новые строки (клиентов, сессии, уроки курсов). Названия колонок должны совпадать с тем, что в **NOTION_И_PLAUD_НАСТРОЙКА.md**.

---

### Шаг 4. Подключить Notion к скрипту (.env)

Скрипт должен знать твой Notion и ID этих трёх баз.

1. В папке **eg-ecosystem** создай файл **.env** (если его ещё нет). Можно скопировать из **.env.example**.
2. В Notion: создай интеграцию (Settings → Connections → Develop or connect apps → New integration). Дай ей доступ к тем страницам/базам, где лежат «Клиенты», «Сессии», «Обучение/курсы». Скопируй **Internal Integration Token** (секретный ключ).
3. Открой базу в Notion в браузере. ID базы — это длинная строка в ссылке между `notion.so/` и `?v=`. Пример ссылки:  
   `https://www.notion.so/workspace/abc123def456...?v=...`  
   Значит ID базы: `abc123def456...` (без `?v=...`). Скопируй ID для каждой из трёх баз.
4. В файл **.env** впиши (подставь свои значения):

```
NOTION_TOKEN=секретный_токен_интеграции
NOTION_DB_CLIENTS=id_базы_Клиенты
NOTION_DB_SESSIONS=id_базы_Сессии
NOTION_DB_COURSES=id_базы_Обучение_курсы
```

Сохрани файл. Больше этот шаг повторять не нужно.

## Часть Б. Каждый вечер: что делать

### 1. Выгрузить аудио с диктофона в inbox_audio

- Подключи диктофон (Plaud или другой) к компу.
- Скопируй все новые записи в папку **inbox_audio**.
- **Важно:** не скидывай всё в кучу в корень inbox_audio. Сразу раскладывай по подпапкам:
  - записи уроков курсов → в **inbox_audio/courses/название_курса/**
  - записи консультаций/сессий клиентов → в **inbox_audio/clients/имя_клиента/**

Если папки для курса или клиента ещё нет — создай её (courses/таз, clients/петров и т.д.) и положи туда файлы.

Итог: в **inbox_audio** лежат только подпапки **courses** и **clients**, а в них — папки по курсам/клиентам, и внутри — твои аудиофайлы.

---

### 2. Запустить одну команду

В терминале:

```bash
cd /Users/egoshev/eg-ecosystem
python scripts/run_pipeline.py
```

(Если проект лежит в другом месте — укажи свой путь после `cd`.)

Скрипт по очереди:

1. Обходит все файлы в **inbox_audio** (и во всех подпапках courses/..., clients/...).
2. По папке понимает: это урок курса или сессия клиента, и как называется курс/клиент.
3. Транскрибирует каждый аудиофайл (текст из голоса).
4. Раскладывает результат у тебя на компе:
   - аудио переносит в **processed/courses/название_курса/** или **processed/clients/имя_клиента/**,
   - транскрипты (текст) сохраняет в **data/transcripts/**.
5. Новых клиентов и сессии добавляет в локальную базу (SQLite).
6. Всё новое отправляет в Notion: создаёт строки в базах «Клиенты», «Сессии», «Обучение/курсы».

После этого в **inbox_audio** обработанных файлов уже не будет — они будут в **processed** и в Notion.

---

### 3. Что в итоге получится

- **На компе:**  
  - Аудио разложено по папкам: **processed/courses/...** и **processed/clients/...**.  
  - Тексты транскриптов — в **data/transcripts/**.

- **В Notion:**  
  - В базе «Клиенты» появятся новые карточки клиентов (если это были первые записи по ним).  
  - В базе «Сессии» — новые сессии с датой, типом и транскриптом, привязанные к клиенту.  
  - В базе «Обучение/курсы» — новые уроки с названием курса, модулем, уроком и транскриптом.

Дальше ты просто открываешь Notion и работаешь с этими базами как обычно.

## Кратко: что помнить

1. **Один раз:** настроил папку inbox_audio, подпапки courses и clients, три базы в Notion, .env с токеном и ID баз, `pip install -r requirements.txt`.
2. **Каждый вечер:** скинул аудио с диктофона в **inbox_audio/courses/...** или **inbox_audio/clients/...**, запустил **python scripts/run_pipeline.py** — всё само разложится по папкам и попадёт в Notion.

Если что-то пойдёт не так (ошибка в терминале, пустой Notion), напиши, на каком шаге застрял — можно будет разобрать по шагам.
