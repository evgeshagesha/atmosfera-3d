# Посты в канал @EvgeniiGoshev: настройка и автопостинг раз в 2 дня

## Почему не отправляется (401 Unauthorized)

Бот может писать в канал **только если**:

1. **В канал добавлен именно тот бот**, чей токен лежит в `TELEGRAM_BOT_TOKEN` (в `.env` и в MCP).  
   Узнать бота: зайди в [@BotFather](https://t.me/BotFather) → /mybots → выбери бота, который создан по этому токену. Запомни юзернейм (например `@IcEG_bot`).

2. **Бот добавлен в канал как администратор** с правом **«Публикация сообщений»** (Post messages):
   - Открой канал [@EvgeniiGoshev](https://t.me/EvgeniiGoshev) → Управление каналом → Администраторы.
   - Добавь бота (по юзернейму из п.1) → включи только «Публикация сообщений» (и при необходимости «Редактирование сообщений других»).

3. **В `.env` указан канал правильно:**
   ```env
   CHANNEL_ID=@EvgeniiGoshev
   ```
   Без пробелов. Для публичного канала достаточно `@EvgeniiGoshev`.

После этого и отправка из Cursor (MCP), и скрипт `generate_channel_post.py --post` будут работать.

## Ручная отправка поста

Из папки бота:

```bash
# Сгенерировать пост (тема по умолчанию — по ротации дня) и отправить в канал
python generate_channel_post.py --post

# Конкретная тема (номер из списка 0–10) и отправить
python generate_channel_post.py 0 --post

# Сгенерировать и сохранить черновик, без отправки
python generate_channel_post.py 0
```

Стиль постов настроен по образцу канала [МАСТЕРСКАЯ ТРЕНЕРОВ](https://t.me/workshop_coaches): разговорно, с вайбиком, с эмодзи, крючок в начале, P.s. при необходимости.

## Автопостинг раз в 2 дня (cron)

Скрипт `run_channel_post_every_2_days.py` генерирует пост через `generate_channel_post.py` и отправляет его в канал.

**На своём компьютере (Mac/Linux):**

```bash
crontab -e
```

Добавь строку (подставь свой путь к проекту):

```cron
0 10 */2 * * cd /Users/egoshev/eg-community-bot && /usr/bin/env python3 run_channel_post_every_2_days.py >> /tmp/channel_post.log 2>&1
```

Это запуск в 10:00 каждые 2 дня (1, 3, 5, 7… числа месяца).

**На VPS (если бот уже крутится на сервере):**

Скопируй в crontab сервера (путь замени на свой):

```cron
0 10 */2 * * cd /path/to/eg-community-bot && python3 run_channel_post_every_2_days.py >> /var/log/eg_channel_post.log 2>&1
```

Проверка вручную:

```bash
cd /Users/egoshev/eg-community-bot
python3 run_channel_post_every_2_days.py
```

В канал уйдёт один сгенерированный пост; в консоль выведется текст или ошибка.

## Очередь готовых постов (опционально)

Если захочешь постить не сгенерированные, а заранее написанные тексты — можно завести файл `channel_posts_queue.txt`: каждая запись — один пост, разделитель `---` между постами. Тогда в `run_channel_post_every_2_days.py` можно добавить логику: если очередь не пуста — брать следующий пост из файла и отправлять; иначе — вызывать `generate_channel_post.py --post`. Сейчас скрипт всегда генерирует пост через AI.
