# Руководство по базе знаний

**Где:** eg-community-bot/knowledge_base/  
**Форматы:** .md и .txt. Загружаются автоматически по имени (00, 01, 02…).

**Как пополнять:** Редактируй или добавляй файлы в knowledge_base. UTF-8. На сервере залей и перезапусти бота: sudo systemctl restart eg-community-bot.

**Шаблоны из экосистемы:** eg-ecosystem/knowledge_templates/ (01_about_evgeny.md … 12_style_and_tone.md) — копируй в knowledge_base при необходимости.

**Ограничение:** Слишком большой объём может не поместиться в контекст OpenAI. Держи ключевые файлы компактными.

**ТЗ и структура:** eg-ecosystem/ТЗ_ЭКОСИСТЕМА_EG.md, СТРУКТУРА_ПАПОК_ЭКОСИСТЕМЫ.md.
