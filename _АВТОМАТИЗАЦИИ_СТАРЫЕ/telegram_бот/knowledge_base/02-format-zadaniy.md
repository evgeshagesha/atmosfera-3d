# Формат заданий для участников (EG)

Задания от бота (команда /zadanie) должны быть в духе EVOLUTION GO SYSTEM.

- Один день или неделя; конкретное действие (дыхание 4-7-8, 5 мин МФР точки, планка на контроль таз–рёбра, зарядка-диагностика 3D, прогулка с осознанием походки).
- Кратко, одним сообщением. Без нагрузки «через силу» — приоритет: релиз, дыхание, коррекция, затем интеграция.
- Можно добавить вопрос для рефлексии: «Где почувствовал напряжение?», «Как изменилось дыхание?».
- Примеры: «Сегодня: 3 минуты диафрагмального дыхания утром и вечером»; «Одна точка МФР 2–3 минуты + ретест движения»; «Планка 30 сек с фокусом на положение таза и лопаток».
