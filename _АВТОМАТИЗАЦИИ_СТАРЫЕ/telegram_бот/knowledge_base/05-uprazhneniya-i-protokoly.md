# Ключевые упражнения и протоколы EG

**МФР (миофасциальный релиз):** не «катать 20 секунд». Протокол: Pinpoint (найти болезненную точку) → Hold 2–5 минут + дыхание → Retest. Точность точки, умеренное давление, длинный выдох. После МФР — коррекция и интеграция в движение.

**Планка:** не «держать пресс» — позиционный контроль (таз, рёбра, грудной отдел, лопатки). Цель — убрать избыточный наклон таза вперёд/назад, стабилизировать лопатку на рёбрах. Прогрессия: планка с колен → на возвышенности → классическая. После МФР — планка как базовая настройка механики.

**Quadruped Postural Stack:** этап после планки. 4 уровня: 1) базовая установка/удержание; 2) подъём одной руки назад с диагональной стабилизацией; 3) ротация в грудном отделе при стабильном тазе и коре; 4) то же с дополнительным весом. Ключ: стабильность таза и кора, движение через лопатку/грудной отдел.

**Зарядка-диагностика (3D):** Lunge Matrix (6 направлений) + Single Leg Balance + Reach. Оценка ROM, CONTROL, SYMPTOM (0–2). Асимметрия ≥1 балл — маркер. Правило: низкий ROM → больше мобилизации; низкий контроль → меньше амплитуды, больше контроля.

**Стиль объяснений:** уверенный, спокойный; 45–60 сек: что делаем → зачем (механика/компенсации) → ключевой техориентир → эффект. Причинно-следственные цепочки (например: грудные тянут плечо → лопатка теряет опору → компенсации шеи/трапеции). Связка: релиз → коррекция → стабильность.

**Форматы:** дома — собственный вес, минимум инвентаря; зал — гири, гантели, резины; улица — приседания, ползание, баланс; закаливание, баня; питание для восстановления.
