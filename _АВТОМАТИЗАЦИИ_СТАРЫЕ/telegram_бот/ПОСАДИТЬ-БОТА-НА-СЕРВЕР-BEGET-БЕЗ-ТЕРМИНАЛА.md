# Как посадить бота на сервер Beget без Терминала на Mac

Ты купил сервер на Beget и хочешь, чтобы бот работал 24/7 через этот сервер. Ниже — что такое SSH и как всё сделать **без Терминала на MacBook**: через панель Beget и программу для файлов.

---

## Что такое SSH

**SSH** (Secure Shell) — это способ удалённо зайти на сервер и выполнять команды, как будто ты сидишь за его консолью. Обычно подключаются так: `ssh логин@IP_сервера` — и вводят пароль. Терминал на Mac как раз и есть программа, где набирают такие команды.

Если не хочешь пользоваться Терминалом на Mac, можно:
1. Заходить на сервер через **веб-консоль** в панели Beget (это тот же доступ к серверу, но в браузере).
2. Заливать файлы бота через **файловый менеджер** в панели Beget или через программу **FileZilla** (SFTP) с Mac.

Ниже — пошагово.

---

## Шаг 1. Вход в панель Beget

1. Зайди на [beget.com](https://beget.com) и авторизуйся.
2. Открой раздел **VPS** (или **Хостинг** → твой VPS).
3. Запомни:
   - **IP сервера** (например, 45.152.87.216).
   - **Логин и пароль** для SSH (часто те же, что и для панели, или отдельные — смотри в письме от Beget или в разделе «Доступ» / «SSH»).

---

## Шаг 2. Залить файлы бота на сервер (без Терминала)

### Вариант А: через панель Beget (файловый менеджер)

1. В панели Beget найди раздел **«Файловый менеджер»** или **«Файлы»** (или **ISPmanager** → «Файлы»).
2. Перейди в домашнюю папку пользователя (часто это `/home/твой_логин` или корень сайта).
3. Создай папку, например `eg-community-bot`.
4. На компьютере Mac открой папку `eg-community-bot` (путь: `/Users/egoshev/eg-community-bot`).
5. **Залей все файлы** из этой папки на сервер в `eg-community-bot`:
   - через «Загрузить файл» / «Upload» в панели загружай по одному или архивом;
   - нужны: `bot.py`, `config.py`, `requirements.txt`, папки `knowledge_base`, `deploy`, `courses_links.json`, `user_state.py` и т.д.;
   - папку `venv` и файл `.env` **не загружай** (venv создадим на сервере, .env создашь там же вручную).

Если панель позволяет загрузить только по одному файлу — можно на Mac упаковать папку в ZIP (без `venv` и без `.env`), залить один ZIP на сервер и в панели распаковать (если есть «Распаковать»).

### Вариант Б: через FileZilla (удобно с Mac, но без командной строки)

1. Скачай [FileZilla](https://filezilla-project.org/) (клиент FileZilla) на Mac.
2. Подключись по **SFTP**:
   - Хост: `IP твоего сервера` (например, 45.152.87.216);
   - Протокол: SFTP;
   - Логин и пароль — те же, что для SSH.
3. Слева — твой компьютер (найди папку `eg-community-bot`), справа — сервер.
4. На сервере создай папку `eg-community-bot` (например, в `/home/твой_логин/`) и перетащи туда все файлы из локальной папки (кроме `venv` и `.env`).

После этого на сервере в папке `eg-community-bot` должны лежать `bot.py`, `requirements.txt`, `knowledge_base` и остальное.

---

## Шаг 3. Запустить команды на сервере (веб-консоль вместо Терминала на Mac)

Чтобы установить зависимости и включить бота 24/7, на сервере нужно выполнить команды. Это можно сделать **в браузере**, если у Beget есть встроенная консоль (SSH-терминал).

1. В панели Beget найди раздел **«Консоль»**, **«SSH-доступ»**, **«Терминал»** или **«Выполнить команды»**.
2. Открой его и войди в сессию (логин/пароль, если попросит).
3. Ты окажешься в командной строке сервера. Дальше — как в инструкции с Терминалом, но команды вводишь здесь:

```bash
cd ~/eg-community-bot
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
```

Если папка бота лежит не в домашней, а в другом месте (например, в `/var/www/egoshev/eg-community-bot`), замени путь в команде `cd ...`.

4. Создай файл `.env` на сервере:
   - через файловый менеджер в панели открой папку `eg-community-bot`;
   - создай файл `.env` (или скопируй `.env.example` и переименуй в `.env`);
   - открой его для редактирования и впиши (подставь свои значения):

```env
TELEGRAM_BOT_TOKEN=твой_токен_бота
OPENAI_API_KEY=твой_ключ_openai
CHANNEL_ID=@EvgeniiGoshev
SITE_URL=https://course.egoshev.ru
ONLINE_CLUB_URL=https://egoshev.ru
```

Сохрани.

5. Запуск бота 24/7 через systemd — снова в веб-консоли. Выполни скрипт настройки (если у тебя есть права на `sudo`):

```bash
cd ~/eg-community-bot
bash deploy/setup-24-7.sh
```

Скрипт создаст systemd-сервис и добавит задания в cron. Если скрипт не запускается (нет прав или нет `sudo`), напиши в поддержку Beget: «Как на VPS включить systemd-сервис или запускать скрипт по расписанию?» — они подскажут для твоего тарифа.

6. Если скрипта нет или он не подходит — сервис можно создать вручную. В веб-консоли (или по SSH с любого компьютера):

```bash
sudo nano /etc/systemd/system/eg-community-bot.service
```

Вставь (путь и пользователя замени на свои):

```ini
[Unit]
Description=EG Community Telegram Bot
After=network.target

[Service]
Type=simple
User=твой_логин
WorkingDirectory=/home/твой_логин/eg-community-bot
Environment=PATH=/home/твой_логин/eg-community-bot/venv/bin
ExecStart=/home/твой_логин/eg-community-bot/venv/bin/python bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Сохрани (в nano: Ctrl+O, Enter, Ctrl+X). Затем:

```bash
sudo systemctl daemon-reload
sudo systemctl enable eg-community-bot
sudo systemctl start eg-community-bot
sudo systemctl status eg-community-bot
```

Должно быть `active (running)`.

## Шаг 4. Проверка

- В Telegram напиши боту в личку: `/start` — должен ответить.
- Добавь бота в канал @EvgeniiGoshev как администратора с правом «Публикация сообщений», чтобы посты из cron уходили в канал.

## Если в панели Beget нет консоли/SSH

На некоторых тарифах веб-консоль отключена. Тогда варианты:

1. **Включить SSH в панели Beget** (если есть пункт «SSH-доступ» или «Включить SSH») и один раз подключиться с Mac: в **Терминале** выполнить `ssh логин@45.152.87.216`, ввести пароль и сделать шаги 3–6 выше. Дальше бот уже будет работать на сервере, Терминал можно закрыть.
2. **Написать в поддержку Beget**: «Как на моём VPS выполнить команды по SSH или через панель? Нужно запустить Python-бота как сервис». Они подскажут под твой тип хостинга.

## Кратко

| Что сделать | Где |
|-------------|-----|
| Залить файлы бота (без venv и .env) | Файловый менеджер Beget или FileZilla (SFTP) |
| Создать .env с токеном и ключами | Редактор в панели или FileZilla |
| Выполнить: venv, pip install, setup-24-7.sh | Веб-консоль/SSH в панели Beget (или один раз SSH с Mac) |
| Проверить бота | Telegram: /start |

После этого бот работает через твой сервер Beget 24/7, без необходимости держать включённым Mac или Терминал.
