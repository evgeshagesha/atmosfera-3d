# Бот для закрытого Telegram-сообщества

Бот ведёт чат: **отвечает на любое сообщение** в чате сообщества, **приветствует новых участников** при входе в группу, выдаёт задания по команде `/zadanie` и разбирает последние сообщения по команде `/analiz`. Всё опирается на базу знаний в папке `knowledge_base/` и OpenAI.

---

## 1. Быстрый старт (локально)

```bash
cd /Users/egoshev/eg-community-bot
cp .env.example .env
# Открой .env и впиши TELEGRAM_BOT_TOKEN и OPENAI_API_KEY

pip install -r requirements.txt   # или: python3 -m pip install -r requirements.txt
python bot.py
```

Бот запустится и будет отвечать в любых чатах, куда его добавят. Чтобы ограничить только своим сообществом — укажи `COMMUNITY_CHAT_ID` в `.env` (см. ниже).

---

## 2. Как «обучать» бота (knowledge_base)

Обучение — это **текстовые файлы** в папке **`knowledge_base/`** (формат `.md` или `.txt`). Бот при каждом ответе и при генерации заданий подгружает их и отдаёт в OpenAI как контекст.

### Что туда класть

| Файл / тема | Зачем |
|-------------|--------|
| Тема и цели сообщества | О чём сообщество, для кого, какой тон — бот будет держать стиль. |
| Формат заданий | Как должны выглядеть задания (/zadanie): длина, тон, примеры. |
| FAQ / частые вопросы | Готовые ответы и формулировки. |
| Правила | Что можно/нельзя, как обращаться, что бот не должен делать. |
| Модули / программы | Краткое описание курсов, блоков, этапов — чтобы бот мог на них ссылаться. |

### Как править

1. Открой папку `knowledge_base/` в Cursor или в любом редакторе.
2. Редактируй существующие файлы или добавляй новые (например: `faq.md`, `pravila.md`, `moduli.md`).
3. Пиши по-русски, кратко и по делу. Чем конкретнее — тем точнее ответы бота.
4. После изменений перезапусти бота (или просто подожди следующего запроса — контент подгружается при каждом обращении к OpenAI).

Удалять файл `00-instrukciya-botu.md` не обязательно; остальные можно переименовывать и дополнять как угодно.

## 3. Команды бота в чате

| Команда | Действие |
|---------|----------|
| `/start` | Приветствие и список команд. |
| `/zadanie` | Сгенерировать задание для участников (на основе knowledge_base + OpenAI). |
| `/analiz` | Краткий разбор последних сообщений в чате и 1–2 предложения, что сделать дальше. |
| Любое сообщение в чате | Бот отвечает на каждое сообщение с учётом базы знаний и OpenAI. |
| Новый участник зашёл в группу | Бот пишет приветствие (тон задаётся в knowledge_base, файл про приветствие). |
| **/link** [курс] | В личку: список ссылок на оплату курсов или ссылка на один курс (breath, posture, pelvis, knees, walk, bundle). |
| **/access НОМЕР_ЗАКАЗА** | В личку: после оплаты в Prodamus — бот выдаёт инвайт-ссылку в нужную группу (5 курсов + 1 «всё вместе»). |

Для `/analiz` бот хранит в памяти последние сообщения в чате (до 30). После перезапуска бота история обнуляется.

## 3a. Ссылки на курсы и доступ после оплаты (Prodamus + 6 групп)

Бот умеет выдавать ссылки на оплату курсов и после оплаты — инвайт в закрытую группу.

- **courses_links.json** — для каждого курса (breath, posture, pelvis, knees, walk, bundle) заполни `prodamus_url` (ссылка на платёжную страницу Prodamus) и `telegram_invite_url` (инвайт-ссылка в группу в Telegram).
- В **личку** боту: «дай ссылку на курс Дыхание» или **/link breath** — бот пришлёт ссылку на оплату. **/access 12345** — после оплаты бот пришлёт ссылку в группу (заказ должен быть в `orders.json`).
- **orders.json** заполняется вебхуком Prodamus. Запусти на сервере `webhook_prodamus.py`, в Prodamus укажи URL уведомлений на этот скрипт. Подробная схема: в проекте сайта см. **ИНТЕГРАЦИЯ-PRODAMUS-И-БОТ.md** (на рабочем столе в папке eg-body-landing).

## 4. ID чата сообщества (COMMUNITY_CHAT_ID)

Чтобы бот реагировал **только** в твоём закрытом сообществе:

1. Добавь бота в нужную группу/супергруппу и дай права на чтение сообщений.
2. Напиши в этой группе любое сообщение.
3. Открой в браузере (подставь свой токен):  
   `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
4. В ответе найди `"chat":{"id": -100xxxxxxxxxx}` — это ID чата. Он отрицательный, например `-1001234567890`.
5. Впиши в `.env`:  
   `COMMUNITY_CHAT_ID=-1001234567890`

Если `COMMUNITY_CHAT_ID` не задан, бот будет отвечать в любом чате, куда его добавят (на упоминания и ответы).

## 5. Запуск бота 24/7 на VPS (Beget)

Бот должен работать круглосуточно, чтобы принимать пользователей с сайта (кнопки ведут в t.me/IcEG_bot?start=...). Запускай его как systemd-сервис.

Чтобы бот работал постоянно, запусти его на своём сервере как systemd-сервис.

### 5.1 Подготовка на сервере

- Подключись по SSH к VPS (например, Beget).
- Установи Python 3.10+ (если нет):  
  `sudo apt update && sudo apt install -y python3 python3-pip python3-venv`
- Создай папку и залей проект (через git, scp или rsync), например в `/home/egoshev/eg-community-bot`.

### 5.2 Виртуальное окружение и зависимости

```bash
cd /home/egoshev/eg-community-bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 5.3 Файл .env на сервере

```bash
cp .env.example .env
nano .env
```

Заполни:

- `TELEGRAM_BOT_TOKEN=...`
- `OPENAI_API_KEY=...`
- `COMMUNITY_CHAT_ID=...` (по желанию)

Сохрани и выйди.

### 5.4 Systemd-сервис

Создай файл (например, от root):

```bash
sudo nano /etc/systemd/system/eg-community-bot.service
```

Содержимое (путь к проекту и пользователю поправь под себя):

```ini
[Unit]
Description=EG Community Telegram Bot
After=network.target

[Service]
Type=simple
User=egoshev
WorkingDirectory=/home/egoshev/eg-community-bot
Environment=PATH=/home/egoshev/eg-community-bot/venv/bin
ExecStart=/home/egoshev/eg-community-bot/venv/bin/python bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Включи и запусти:

```bash
sudo systemctl daemon-reload
sudo systemctl enable eg-community-bot
sudo systemctl start eg-community-bot
sudo systemctl status eg-community-bot
```

Дальше:

- Логи: `journalctl -u eg-community-bot -f`
- Перезапуск после правок: `sudo systemctl restart eg-community-bot`

## 6. Кратко: что делать по шагам

1. **Создать и заполнить `.env`** (токен бота, OpenAI, при желании COMMUNITY_CHAT_ID).
2. **Заполнить `knowledge_base/`** — тема сообщества, формат заданий, правила, FAQ.
3. **Запустить локально** (`python bot.py`) и проверить в тестовой группе.
4. **Добавить бота в закрытое сообщество**, при необходимости указать COMMUNITY_CHAT_ID.
5. **Для 24/7** — залить проект на VPS и настроить systemd по разделу 5.
6. **Ежедневные 15 сообщений** — на VPS по cron раз в день запускать `python run_daily_messages.py` (например в 9:00). Скрипт отправляет каждому из списка 15 дожимающих сообщений (сейчас генерирует AI; тексты можно заменить на свои в скрипте или через knowledge_base).
7. **Ежедневный опрос в группе** — раз в день запускать `python run_daily_group_checkin.py` (например в 9:00). Скрипт отправляет в чат **COMMUNITY_CHAT_ID** одно сообщение: как самочувствие, делали ли тренировку (по-человечески). Участники отвечают в чат — бот (уже отвечает на каждое сообщение) поддерживает и при необходимости даёт короткий корректив в программу на сегодня (лёгкий день, МФР+дыхание при боли и т.д.). В `.env` обязательно указать **COMMUNITY_CHAT_ID** (ID группы EGcommunity), иначе скрипт не отправит сообщение.

После любых правок в `knowledge_base/` достаточно перезапустить бота (или дождаться следующего запроса), менять код не обязательно.
