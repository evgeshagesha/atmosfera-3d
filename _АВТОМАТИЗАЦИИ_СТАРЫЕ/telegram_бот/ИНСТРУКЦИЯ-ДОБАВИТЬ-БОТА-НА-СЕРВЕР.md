# Пошаговая инструкция: как посадить бота на сервер (VPS)

Бот будет работать **24/7 через твой сервер** — отвечать в Telegram, постить в канал, выдавать доступ после оплаты. Ниже — что сделать по порядку.

---

## Кратко: что сделать по шагам

| № | Действие | Где делать |
|---|----------|------------|
| 1 | Подключиться к серверу по SSH | Терминал на Mac: `ssh пользователь@45.152.87.216` |
| 2 | Проверить Python 3 (`python3 --version`), при необходимости установить | На сервере |
| 3 | Создать папку: `mkdir -p ~/eg-community-bot` | На сервере |
| 4 | Скопировать папку **eg-community-bot** с компьютера на сервер (scp или rsync) | С компьютера (второе окно Терминала) |
| 5 | На сервере запустить: `cd ~/eg-community-bot && bash deploy/setup-24-7.sh` | На сервере |
| 6 | Отредактировать `.env` на сервере: токен бота, OpenAI, CHANNEL_ID | На сервере: `nano ~/eg-community-bot/.env` |
| 7 | Перезапустить бота: `sudo systemctl restart eg-community-bot` | На сервере |
| 8 | Добавить бота в канал @EvgeniiGoshev как администратора с правом «Публикация сообщений» | В Telegram |

После этого бот уже работает через твой сервер. Подробности каждого шага — ниже.

---

## Что понадобится заранее

- **Доступ по SSH** к серверу (логин и пароль или SSH-ключ).
- **IP сервера** (например, 45.152.87.216 для Beget) или домен, который на него указывает.
- **Токен бота** из [@BotFather](https://t.me/BotFather) (уже есть в `.env` на компьютере).
- **OpenAI API ключ** (уже в `.env`).
- Папка **eg-community-bot** на твоём компьютере (где лежат `bot.py`, `requirements.txt`, `.env.example`).

---

## Шаг 1. Подключись к серверу по SSH

На Mac/Linux открой **Терминал** и выполни (подставь своего пользователя и IP):

```bash
ssh твой_пользователь@45.152.87.216
```

Пример: если пользователь на Beget — `egoshev`, то:

```bash
ssh egoshev@45.152.87.216
```

Введи пароль, когда попросит. Оказался в консоли сервера — переходи к шагу 2.

---

## Шаг 2. Установи Python 3 (если ещё нет)

Проверь, есть ли Python:

```bash
python3 --version
```

Если версия 3.8 или выше — всё ок. Если команды нет или версия старая, установи (для Ubuntu/Debian):

```bash
sudo apt update
sudo apt install -y python3 python3-pip python3-venv
```

Проверь снова: `python3 --version`.

---

## Шаг 3. Создай папку для бота на сервере

Например, в домашней директории:

```bash
mkdir -p ~/eg-community-bot
cd ~/eg-community-bot
```

Запомни путь: он понадобится для systemd. Часто это `/home/egoshev/eg-community-bot` (подставь своего пользователя вместо `egoshev`).

---

## Шаг 4. Залей файлы бота на сервер

Сделать это нужно **с твоего компьютера** (открой **новое** окно Терминала и не закрывай сессию SSH).

**Вариант А — через SCP (копирование папки):**

```bash
cd /Users/egoshev
scp -r eg-community-bot твой_пользователь@45.152.87.216:~
```

Пример: `scp -r eg-community-bot egoshev@45.152.87.216:~`

**Вариант Б — через rsync (удобно для обновлений):**

```bash
cd /Users/egoshev
rsync -avz --exclude 'venv' --exclude '__pycache__' --exclude '.env' eg-community-bot/ твой_пользователь@45.152.87.216:~/eg-community-bot/
```

Файл `.env` не копируем — его создашь на сервере вручную (шаг 6), чтобы не светить секреты.

После выполнения команды зайди снова по SSH и проверь:

```bash
cd ~/eg-community-bot
ls -la
```

Должны быть файлы: `bot.py`, `requirements.txt`, `config.py`, папки `knowledge_base`, `deploy` и т.д.

---

## Шаг 5. Запусти скрипт настройки на сервере

В сессии SSH (ты в `~/eg-community-bot`):

```bash
cd ~/eg-community-bot
bash deploy/setup-24-7.sh
```

Скрипт:

- создаст виртуальное окружение `venv` и установит зависимости;
- если нет `.env` — скопирует из `.env.example` (его потом нужно отредактировать);
- создаст и включит systemd-сервис `eg-community-bot`;
- добавит задания в cron (ежедневные сообщения и пост в канал).

Если скрипт спросит пароль для `sudo` — введи пароль пользователя сервера.

---

## Шаг 6. Настрой файл .env на сервере

Открой `.env`:

```bash
nano ~/eg-community-bot/.env
```

Заполни (или проверь) строки:

```env
TELEGRAM_BOT_TOKEN=7720554188:AAE...ваш_токен...
OPENAI_API_KEY=sk-...ваш_ключ...
SITE_URL=https://course.egoshev.ru
ONLINE_CLUB_URL=https://egoshev.ru
CHANNEL_ID=@EvgeniiGoshev
```

По желанию:

- `COMMUNITY_CHAT_ID=-1001234567890` — ID группы EGcommunity (как узнать — см. README, раздел 4).

Сохрани: `Ctrl+O`, Enter, выход: `Ctrl+X`.

---

## Шаг 7. Перезапусти бота и проверь статус

```bash
sudo systemctl restart eg-community-bot
sudo systemctl status eg-community-bot
```

Должно быть: `active (running)`. Если `failed` — смотри логи:

```bash
journalctl -u eg-community-bot -n 50 --no-pager
```

Частые причины ошибок: неверный `TELEGRAM_BOT_TOKEN`, опечатка в путях в unit-файле (проверь пользователя и путь к папке в `eg-community-bot.service`).

---

## Шаг 8. Добавь бота в канал и группу (если ещё не добавлен)

- **Канал @EvgeniiGoshev:** Управление каналом → Администраторы → Добавить → найдите бота по юзернейму (например @IcEG_bot) → включи право **«Публикация сообщений»**.
- **Группа EGcommunity (если используешь):** добавь бота в группу, при необходимости выдай права на чтение/написание.

Без этого бот не сможет постить в канал (ошибка 401) и не будет видеть сообщения в группе.

---

## Шаг 9. Проверка работы

1. Напиши боту в личку в Telegram: `/start` — должен ответить.
2. Зайди в канал @EvgeniiGoshev — пост по расписанию (cron в 10:00) должен появляться, если бот админ.
3. В группе (если настроена) — напиши сообщение, бот должен реагировать (если настроен на эту группу через `COMMUNITY_CHAT_ID`).

---

## Полезные команды на сервере

| Действие | Команда |
|----------|--------|
| Статус бота | `sudo systemctl status eg-community-bot` |
| Перезапуск бота | `sudo systemctl restart eg-community-bot` |
| Смотреть логи в реальном времени | `journalctl -u eg-community-bot -f` |
| Последние 100 строк логов | `journalctl -u eg-community-bot -n 100 --no-pager` |
| Редактировать .env | `nano ~/eg-community-bot/.env` |
| Посмотреть cron | `crontab -l` |

---

## Если путь или пользователь на сервере другие

Скрипт `setup-24-7.sh` подставляет текущего пользователя и текущую папку в unit-файл. Если ты загрузил бота не в `~/eg-community-bot`, а, например, в `/var/www/eg-community-bot`, то после первого запуска скрипта отредактируй сервис:

```bash
sudo nano /etc/systemd/system/eg-community-bot.service
```

Измени строки `User=`, `WorkingDirectory=`, `Environment=`, `ExecStart=` на свои путь и пользователя. Затем:

```bash
sudo systemctl daemon-reload
sudo systemctl restart eg-community-bot
```

## Краткая шпаргалка (одним списком)

1. Подключись по SSH к серверу.
2. Установи Python 3 (если нужно).
3. Создай папку `~/eg-community-bot`.
4. С компьютера залей туда файлы бота (scp или rsync), **без** `.env`.
5. На сервере: `cd ~/eg-community-bot && bash deploy/setup-24-7.sh`.
6. Отредактируй `.env`: токен бота, OpenAI, CHANNEL_ID, при необходимости COMMUNITY_CHAT_ID.
7. Перезапусти: `sudo systemctl restart eg-community-bot`.
8. Добавь бота в канал @EvgeniiGoshev как администратора с правом публикации.
9. Проверь: `/start` в личку, канал и группу.

После этого бот работает на сервере 24/7, ежедневные задачи выполняет cron.
