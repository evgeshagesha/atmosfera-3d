## 🚀 Что сделать тебе (2 шага)

### Шаг 1 · Перезагрузи Cursor
**Cmd + Shift + P** → `Developer: Reload Window`

### Шаг 2 · Первый запуск (один раз)
В новом чате Agent напиши:

```
/t800-bootstrap
```

T-800 покажет, что уже стоит в Cursor, и предложит глобальное правило маршрутизации (по желанию).

---

## 📖 Основные команды

| Команда | Зачем |
|---|---|
| `/t800-bootstrap` | Первый запуск, обзор системы |
| `/t800-start` | Создать skill / агента / rule / hook |
| `/t800-audit` | Проверить Cursor на лишнее и хаос |
| `/t800-fix` | Поправить по результатам аудита |
| `/t800-doctor` | Быстрая диагностика «жив ли плагин» |
| `/t800-onboard` | Напомнить, что умеет отдел |
| `/t800-plugin-audit` | Разбор одного плагина |
| `/t800-loop` | Закрыть прогон: отчёт, уроки, очередь |

## 💡 Примеры для твоего бизнеса

**Создать агента продаж под Атмосферу 3D:**
```
/t800-start
Создай субагента для продаж в директ Instagram — тон премиальный, 
диагностический подход, продукты из 00_ПУЛЬТ_УПРАВЛЕНИЯ/ГЛАВНЫЙ_КОНТЕКСТ.md
```

**Проверить, не захламлён ли Cursor:**
```
/t800-audit
```

**Создать skill для контента Reels:**
```
/t800-start
Skill: сценарии Reels для Атмосфера 3D, русский язык, стиль Notion в документах
```

## 🔄 Обновление

Плагин **сам проверяет GitHub** при новом чате. Если вышла новая версия — скачает и попросит Reload Window.

Ручное обновление:
```
/t800-update
```

---

## ⚠️ Важно

- T-800 ставится **глобально** в Cursor — работает во всех проектах, не только в `atmosfera-3d`.
- Не путать с папкой `03_РЕСУРСЫ/плагины/t-800-agent/` — это **архивная копия** для справки.
- После `/t800-bootstrap` может предложить правило «всё через T-800» — решай сам, нужно ли тебе.
