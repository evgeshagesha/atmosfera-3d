## Суть

Продуктовая лестница EG OS: человек входит через ясность/диагностику → получает **один следующий шаг** → растёт от самостоятельной практики к сопровождению. Не каталог услуг.

Формула: *сначала качество движения → затем сила*.

- Детский **Movement Camp EG** (Москва, 4–5 детей, ~4 часа): биомеханика, стопы/таз/осанка/дыхание, баланс, ОФП без ранней специализации, рекомендации родителям.
- Будущее: мед.образование в позиционировании, диагностическое оборудование, детская анкета + AI-разбор, интеграция в сайт/воронки/CRM/бот/Journey.
- Онлайн-тренировки и очные индивидуальные занятия — в актуальной линейке рядом с консультацией.

## Правила для AI

1. Не продавать медобещания / диагнозы / «лечение» без правовой базы.
2. Новый продукт = задача + границы + измеримый результат + следующий шаг.
3. Контент ≠ продукт: контент даёт ясность; продукт организует изменение.
4. Детская цена ~30к — гипотеза; на сайте всегда указывать **за кого / за что**.
