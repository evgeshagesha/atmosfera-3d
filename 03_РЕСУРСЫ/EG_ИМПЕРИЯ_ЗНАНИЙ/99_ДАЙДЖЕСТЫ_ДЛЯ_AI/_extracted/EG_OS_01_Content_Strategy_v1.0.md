EG OS — 01_CONTENT_STRATEGY v1.0

Роль этого документа

Этот документ определяет всю контентную стратегию бренда Евгения Гошева.

Контент создаётся не ради просмотров.

Контент создаётся для формирования доверия, экспертности и перевода
человека по воронке продаж.

------------------------------------------------------------------------

Главная цель контента

Не собрать максимальное количество просмотров.

А стать самым понятным русскоязычным экспертом по здоровью через
движение.

Каждый ролик должен отвечать на вопрос:

«Почему зритель должен доверять именно Евгению?»

------------------------------------------------------------------------

Главная идея бренда

Сложные вещи объясняются простым языком.

Любая тема должна быть понятна человеку без медицинского образования.

------------------------------------------------------------------------

Контент-пирамида

1. Вирусный контент (40%)

Цель: Привлечь новую аудиторию.

Форматы: - упражнения; - двойник; - дыхание; - мобильность; - тесты; -
«что будет, если…».

CTA: Подписка или получение бесплатного гайда.

------------------------------------------------------------------------

2. Экспертный контент (25%)

Цель: Показать глубину знаний.

Форматы: - почему болит; - почему не помогает; - разбор ошибок; -
объяснение механизмов.

CTA: Пройти тест.

------------------------------------------------------------------------

3. Истории и кейсы (25%)

Цель: Создать доверие.

Форматы: - история клиента; - случай из практики; - путь
восстановления; - история спортсмена.

Структура: Проблема → Диагностика → Решение → Результат → Следующий шаг.

------------------------------------------------------------------------

4. Личный бренд (10%)

Цель: Сделать так, чтобы люди подписывались на человека.

Форматы: - мысли после рабочего дня; - наблюдения; - жизнь; -
дисциплина; - тренировки; - путь спортсмена.

------------------------------------------------------------------------

Контент никогда не публикуется случайно

Перед созданием любого материала Cursor должен определить:

1.  Цель ролика.
2.  Этап воронки.
3.  Формат.
4.  Главную мысль.
5.  CTA.
6.  Возможность переработки в:
    -   Stories;
    -   Telegram;
    -   YouTube Shorts;
    -   длинный YouTube;
    -   статью.

------------------------------------------------------------------------

Правила качества

Каждый сценарий должен иметь:

• сильный хук; • одну главную мысль; • простые слова; • историю или
пример; • визуальные идеи; • естественный CTA.

Не перегружать информацией.

Один ролик = одна идея.

------------------------------------------------------------------------

Производственная система

Раз в неделю снимается пакет роликов.

Монтаж, AI-вставки, публикации и адаптация выполняются отдельно.

Контент должен быть масштабируемым.

После завершения этого документа остановись и жди следующего задания.
