## Как пользоваться со мной в Cursor

1. Укажи книгу через `@` или напиши название из каталога.
2. Задача, например:
   - «По Капанджи (позвоночник) объясни механику наклона для клиента со скованностью»
   - «Собери мини-блок из FP + логика из Анатомических поездов»
   - «Разбери упражнение через анатомию силовых / стретчинга»
3. Результат кладём в `01_заметки_и_выжимки/` или в карточку клиента / программу.

> 💡 Я не «запоминаю» 545 МБ за один раз. Книги — **открытая библиотека**: по запросу открываем нужный том и строим программу. Чем чаще делаем выжимки — тем быстрее ответы.
