## 2. Три типа документов (канон MASTER)

| Тип | Когда | Задача для клиента | Объём (ориентир) |
|---|---|---|---|
| **№1 · Рекомендации после сессии** | После 1-й очной диагностики | Зафиксировать главное + первые действия | 15–21 стр. (как Наталья/Медин/Денис) |
| **№2 · Персональный план на месяц** | После диагностики / консультации | Система на ~30 дней: режим + тренировки + якоря | 15–30+ стр. (Дарья / Наталья 30д) |
| **№3 · Долгосрочное ведение** | Премиум-сопровождение | «У меня есть специалист, который ведёт меня» | Будущий продукт · 100–150k+ 🔶 |

**Что продаём через документ (не PDF и не «набор упражнений»):**  
спокойствие → понимание → уверенность → контроль → движение к здоровому телу.

### Четыре обязательных вопроса (каждый документ)

1. **Что происходит?** — человек понимает своё состояние  
2. **Почему мы это делаем?** — логика работы  
3. **Что мне делать?** — конкретные действия + дозировка  
4. **Что будет дальше?** — следующий этап / сессия / продукт  

Если хотя бы один ответ размыт — документ не готов.

## 3. Визуальный стиль (из PDF)

### 3.1. Две визуальные ветки (важно)

| Ветка | Референсы | Характер |
|---|---|---|
| **A · Premium Cover (канон-кандидат)** | Наталья рекомендации · Медин · Денис · Дарья | Чёрный фон, EG-лого слева сверху, wide-tracking лейблы, тонкая линия, метаданные Клиент/Формат/Дата/Специалист, футер «ДВИЖЕНИЕ · ДЫХАНИЕ · ДИСЦИПЛИНА» |
| **B · Dense Program** | Наталья 30 дней | Тёмный фон + декоративные линии, плотнее текст, таблицы с 1-й страницы, «ПЕРСОНАЛЬНАЯ ПРОГРАММА» |

> 💡 Предложение: **канон = ветка A** для обложки и TOC; таблицы/режим дня — из ветки B. Не смешивать два «лица» без нужды.

### 3.2. Цвет и фон

| Токен | Практика в PDF | Примечание |
|---|---|---|
| Фон | Глубокий чёрный / near-black | Согласуется с EG Premium |
| Основной текст | Белый | Высокий контраст |
| Вторичный / лейблы | Серый medium | Wide letter-spacing CAPS |
| Акцент | Сдержанный (без cyan-шума в обложках) | Cite Premium: серебро `#d8dde4`; cyan — устаревший в Premium SoT |

**Запрет визуала:** пёстрый фитнес, золото/оранж, карточки-шум, острые «баннерные» углы, перегруженные страницы.

### 3.3. Типографика и иерархия

| Уровень | Как выглядит в PDF |
|---|---|
| Бренд-строка | CAPS + tracking: «АТМОСФЕРА ЗДОРОВЬЯ» / «АТМОСФЕРА 3D» |
| Продуктовая строка | «БАЗОВАЯ НАСТРОЙКА ТЕЛА · РЕКОМЕНДАЦИИ» или «МЕСЯЧНЫЙ ПЛАН · …» |
| H1 обложки | Крупный bold sans: «Рекомендации после первой сессии» / «Месячный план…» |
| Подзаголовок | 1–2 предложения: что документ даёт человеку |
| Фокус-линия | Серая строка через «·» (зоны тела) |
| Секции | Номер `01` + CAPS-лейбл + живой H2 |
| Тело | Короткие абзацы, 3–6 строк; «дыхание» страницы |
| Футер | Клиент · EG · номер страницы |

Шрифт: гротеск премиум (в рендере — Manrope / стек из design-tokens). Не Word-дефолт.

### 3.4. Обложка (обязательный каркас ветки A)

1. Логотип EG  
2. Бренд + продуктовая строка  
3. H1  
4. Подзаголовок (человеческий benefit)  
5. Фокус-зоны через «·»  
6. Тонкая линия  
7. Мета: **Клиент / Формат / Дата (или Период) / Специалист**  
8. Футер-столпы  

### 3.5. Знаки и блоки

- Нумерация секций крупным «призрачным» номером или `01`  
- Callout безопасности (рамка): «Безопасность — приоритет»  
- Таблицы только там, где ускоряют понимание (сигнал→гипотеза→решение; недельный каркас; тарелка)  
- Разделители — тонкие линии, не тяжёлые боксы

## 4. Язык и тон

### 4.1. Баланс

**Профессиональность + понятность + спокойствие + уверенность + забота**

Не: медсправка · сухой план · «ещё один тренер» · научная статья · инфоцыганство.

### 4.2. Формула объяснения

`Что наблюдаем → почему важно → что делаем → какой ориентир результата`

В MASTER: та же логика + 4 вопроса финала.

### 4.3. Слои языка (одновременно)

| Слой | Примеры | Правило |
|---|---|---|
| Биомеханика | паттерн, компенсация, кинетическая цепь, распределение нагрузки | Термин + человеческая расшифровка |
| Анатомия | грудной отдел, ягодичные, сгибатели бедра | Корректно; рядом — простое объяснение |
| Физкультура | объём, интенсивность, прогрессия, восстановление | Реалистичная дозировка |
| Реабилитационный | постепенность, контроль симптомов, дозирование | Без медобещаний |
| Человеческий | «тело тебя слушается», «вернём работу туда, где ей место» | Тёпло, без сюсюканья |

### 4.4. Обращение

- Клиентские PDF: **«ты»** + имя в ключевых местах  
- Не диагнозы; находки МРТ/снимков — «как читать», не ярлык личности  
- Рамка: «тело адаптировалось» / «подстроилось» — не «ты сломан»

### 4.5. Анти-ИИ и голос (из 10-voice + PDF)

- «не X, а Y» — максимум редко; в premium почти нет  
- Конкретика сессии важнее красивой симметрии  
- Клиническая точность > красота истории (пример из 50-programs: грушевидная слева vs ягодичные)  

### 4.6. Запреты (жёстко)

Не писать: вылечу · гарантированно уберём боль · исправим позвоночник · вылечим грыжу · уберём артроз · секретный/революционный метод · тело мечты · вау/топ/🔥.

Можно: «наша задача» · «будем работать над» · «может улучшить» · «отслеживаем реакцию» · «при усилении — к специалисту».

Добавки / анализы: панель можно предложить; **приём добавок — только через врача клиента**.

## 5. Структура по типам

### 5.1. Тип №1 — Рекомендации после сессии  
*(канон: Наталья · Медин · Денис)*

| Блок | Содержание |
|---|---|
| Обложка A | см. §3.4 |
| TOC | «Карта документа» · 15–18 пунктов |
| 01 Первая сессия | Что увидели · сильные стороны сначала · одна фраза-якорь на месяц |
| 02 История / контекст | Как читать находки; без запугивания |
| 03 Карта тела | Зоны и связи (стопа→…→шея) |
| 04 Главный механизм | Куда уходит напряжение / кто «отрабатывает за» |
| 05 Приоритеты | 3–5 направлений, не 20 проблем |
| 06–11 Протоколы | МФР · дыхание · активации · мобильность · кор · шея (по кейсу) |
| 12 Тренировки / активность | Как перестроить, не «убиться» |
| 13 Восстановление | Вода, сон, питание, НС (по кейсу) |
| 14 Быт / день | Микропаузы, эргономика |
| 15 Безопасность | Клапан боли + красные флаги |
| 16 Маркеры прогресса | Как понять, что идёшь верно |
| 17 Что дальше | План / курс / клуб / студия — как логичный next step |
| 18 Итог | Шаг за шагом |
| Подвал | Ссылки · дисклеймер · (аккуратный отзыв Яндекс — по 50-programs) |

**МФР-метод (канон):** фиксация точки → активное укорочение↔удлинение → ~2 мин → смещение вдоль мышцы. Не пассивное катание.

### 5.2. Тип №2 — Персональный план на месяц  
*(канон-кандидат: Дарья; плотный каркас: Наталья 30д)*

| Блок | Содержание |
|---|---|
| Обложка A | «Месячный план…» + период |
| Как устроен месяц | 4 недели = 4 этапа (канонические названия фаз) |
| Карта тела / что возвращаем | Связь с разбором 1-й сессии |
| Недельный каркас | День · формат · содержание |
| Ежедневные якоря | Вода · дыхание · шаги · короткий блок |
| Недели 1–4 | Детализация по фазам |
| Библиотека упражнений | Название · цель · дозировка · видео |
| Питание / сон / дыхание | Только если входит в работу с этим человеком |
| Безопасность + маркеры | Обязательно |
| Итог 30 дней + next | Месяц 2 / студия / клуб |

**Канон фаз (в клиентском тексте):**  
1. снятие напряжения и гидратация тканей  
2. корректирующие упражнения и двигательная база  
3. полноценные функциональные тренировки  
4. прогрессия нагрузки  

Не называть фазы «освобождение / коррекция / интеграция» в клиентском PDF.

**Модель недели:** сила не каждый день; микс сила + движение/координация + ежедневная мобильность + день восстановления.

### 5.3. Тип №3 — Долгосрочное ведение  
*(референс PDF пока нет — каркас из MASTER)*

Цели · исходная оценка · ограничения · приоритеты · этапы · тренировочная система · ежедневные якоря · дыхание/мобильность/сила · восстановление · закаливание (если уместно) · питание/сон · контроль нагрузки · промежуточные проверки · критерии прогресса · правила связи · корректировки · видео · следующий этап.

Ощущение: персональное сопровождение, не «ещё один PDF».

## 6. Упражнения, видео, библиотека

Формат единицы:

`НАЗВАНИЕ → краткое описание → цель → дозировка (повт./время/частота) → ВИДЕО-ссылка`

- Источник видео: Telegram-библиотека (`t.me/egoshevuprazhneniya` и актуальные deep-link’и)  
- Если упражнения нет в библиотеке: `[НУЖНО ДОБАВИТЬ УПРАЖНЕНИЕ В БИБЛИОТЕКУ]`  
- Не выдумывать URL  
- Не просить у клиента видео себя

## 7. Персонализация

Обязательно уникально:

- имя и контекст жизни (профессия, занятость)  
- реальные наблюдения с сессии (мяч, бревно, присед на пятках…)  
- одна «фраза-якорь» на период  
- приоритеты 3–5, не dump всех находок  
- safety-блок под конкретные симптомы  

Не добавлять клинические выводы «от себя», если Евгений дал черновик — только структурировать и прояснить.

---

## 8. Продажа без агрессии

Порядок: ценность → ясность → логика продолжения → предложение.

В конце допустимы: месячный план · курс «Базовая…» · клуб · очные сессии.  
Цены/URL — только из `products.yaml` / 20-products (не выдумывать).  
Отзыв Яндекс.Карты — мягкий CTA после этапа.

|---|---|

| Анатомия | Термины корректны? |

| Rehab | Постепенность? Контроль симптомов? |
| Язык | Понятно без медобразования? Не холодно? |

## 12. Связь с методом EG

Маршрут внутри документа всегда отражает:

`Диагностика → Регуляция → Коррекция / база → Интеграция / функционал → Стабилизация`

## Что я понял о твоей системе

Ты продаёшь не PDF и не список упражнений, а **ясность после живой диагностики**: человек должен уйти с ощущением «меня услышали → я понимаю механизм → у меня есть спокойный план».

Документы живут лестницей: **рекомендации (фиксация) → месяц (система привычек) → ведение (человек рядом)**. Визуально у тебя уже есть сильная ветка A (чёрная обложка EG, метаданные, столпы) — это и есть лицо премиума. Язык — биомеханика с человеческой расшифровкой, сильные стороны сначала, одна фраза-якорь, приоритеты вместо dump’а проблем. Безопасность и «не лечим диагнозы» — не дисклеймер в конце, а часть метода. МФР у тебя **активный**, не пассивный. Коммерческий хвост — логичный next step, не рекламная простыня.
