## Зачем эта папка

Сюда кидай всё, из чего потом строим:

- бренд и EG OS
- контент-систему
- клиентский путь
- зарубежные и текущие обучения
- методику и практику
- идеи продуктов и школы
- анализ рынка / что продаётся

`90_ВХОДЯЩИЕ/` — разовый dump.  
`03_РЕСУРСЫ/EG_ИМПЕРИЯ_ЗНАНИЙ/` — кураторский склад империи.

## Как кидать материалы

1. Новое сырьё → `00_ВХОДЯЩИЕ_СЫРЬЁ/`
2. В чате: «разложи входящие знаний» или «проиндексируй EG_ИМПЕРИЯ_ЗНАНИЙ»
3. Обучения / курсы → `04_ОБУЧЕНИЯ_И_КУРСЫ/`
4. Практика / протоколы → `05_МЕТОДИКА_И_ПРАКТИКА/`
5. Продуктовые идеи → `06_ПРОДУКТЫ_И_ШКОЛА/`
6. Конкуренты / рынок → `07_АНАЛИЗ_РЫНКА/`
