> Короткие учебные клипы: одно упражнение — одна ясная техника. Справочник, не дневная практика.

| | |
|---|---|

## 🎯 Правила серии

- Одно упражнение = один ролик. Не собирать сюда 10-минутные комплексы.
- Полные зарядки остаются в утреннем / вечернем / full-body плейлистах.
- Допустимо дублировать фрагмент длинного видео как отдельный учебный клип (второй плейлист у длинного — не обязателен).
