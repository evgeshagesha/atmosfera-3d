## 🎧 Общие решения

- **Ритм:** документальный, спокойный, смысловые смены без случайных эффектов.
- **Монтаж:** purposeful cuts; J/L cuts — только когда улучшают связность.
- **Звук:** голос и разборчивость первичны.
- **Цвет:** естественная кожа, единый баланс и контраст.
- **AI:** только для точной реплики, не декоративно.
- **Remotion:** опционально для повторяемой графики/Shorts, не обязательный long-form timeline.

## ⛔ STOP-GATE

- [ ] Все обязательные файлы доступны.
- [ ] Основной CTA утверждён.
- [ ] Непроверенные claims отмечены.
- [ ] Для каждой AI-вставки есть точная реплика и approve.
- [ ] Нет указаний на случайные zoom/effects.
- [ ] Понятны дедлайн и число раундов правок.

Rough cut не переводится в финал до `Approval state: ROUGH_CUT_APPROVED_BY_EG`.
