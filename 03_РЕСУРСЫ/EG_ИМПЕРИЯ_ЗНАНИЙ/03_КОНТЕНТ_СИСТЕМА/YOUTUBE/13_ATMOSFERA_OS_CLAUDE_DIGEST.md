## 🎬 Два формата длинных роликов (канон)

### A. Экспертный разбор — 10–18 мин

Структура из `02_LONG_VIDEO_SYSTEM.md` (не менять):  
Hook → проблема → заблуждение → механизм → практика → шаги → ограничения → итог → CTA тест.

Съёмка: talking head (камера A) + детали (B) + 1 блок практики в полный рост.

### B. Тренировка / follow-along — 12–25 мин

1. 20–40 сек: для кого + что изменится + безопасность.
2. Разминка 2–3 мин.
3. Основной блок: упражнение → 1 чистый повтор → 2–3 точки → повтор с тобой.
4. Финиш / дыхание.
5. Один CTA (тест или anketa).

Съёмка: штатив полный рост 16:9; опционально телефон 9:16 одновременно; звук петличка обязательна.
