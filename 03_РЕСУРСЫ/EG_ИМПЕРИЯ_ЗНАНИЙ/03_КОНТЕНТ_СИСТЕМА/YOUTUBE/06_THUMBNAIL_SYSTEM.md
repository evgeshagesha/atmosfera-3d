# 🖼 Система YouTube-обложек EG

> Обложка не кричит и не обещает невозможного. Она за долю секунды показывает одну телесную проблему или одно движение и создаёт точное ожидание от видео.

---

## 📋 Свойства

| | |
|---|---|
| **Статус** | 🟢 Визуальный стандарт |
| **Главный герой** | Реальная фотография Евгения |
| **Текст** | 2–5 слов |
| **Палитра** | Тёмный графит · белый · cyan-акцент |
| **Главный критерий** | Понятность на мобильном экране |
| **Обновлено** | 29.07.2026 |

---

## 🎯 Формула обложки

```text
реальный Евгений
+ одна проблема или одно движение
+ короткая смысловая фраза
+ один cyan-акцент
```

Примеры смысловых направлений:

- `СТОПА НЕ ДЕРЖИТ?`
- `ТАЗ НЕ ДВИГАЕТСЯ`
- `ДЫШИТЕ СВОБОДНЕЕ`
- `ПРОВЕРЬТЕ ОПОРУ`
- `НЕ ТОЛЬКО СПИНА`

Текст обложки не повторяет заголовок дословно. Заголовок даёт контекст и пользу, обложка — мгновенный визуальный конфликт.

---

## 🧍 Фото Евгения — сначала

Приоритет:

1. Реальный кадр Евгения, снятый специально под тему.
2. Реальный кадр демонстрации движения.
3. Реальная деталь тела без искажения и сенсационности.
4. Простая схема — только если без неё невозможно понять тему.

Запрещено:

- AI-лицо или подмена внешности Евгения;
- чрезмерно изменённая мимика;
- фальшивая анатомия;
- красные «воспалённые» зоны без доказательной необходимости;
- рентген-эффекты, которых не было в исходнике;
- стоковый «больной человек» вместо автора;
- пугающие стрелки, круги и медицинские ярлыки.

## 🎨 Визуальная система

| Элемент | Правило |
|---|---|
| **Фон** | Тёмный графит, контролируемая студия, минимум деталей |
| **Текст** | Белый, крупный, 2–5 слов |
| **Акцент** | Cyan на одном слове, линии движения или точке внимания |
| **Евгений** | 40–65% площади, лицо или полный жест читается |
| **Проблема** | Только одна зона или одно движение |
| **Графика** | Одна линия, стрелка или простая рамка |
| **Логотип** | Не обязателен; не конкурирует с главным смыслом |
| **Воздух** | Свободное пространство вокруг текста и лица |

### Композиции

**A. Лицо + тезис**  
Для заблуждений, разборов и личных историй.

**B. Полный рост + линия движения**  
Для практики, походки, опоры и координации.

**C. Евгений + одна деталь**  
Для стопы, дыхания, грудной клетки или таза.

Не использовать более двух главных объектов.

---

## ✍️ Правила текста

- 2–5 слов, без мелкого подзаголовка.
- Один смысл, читаемый без названия видео.
- Конкретный глагол или проблема сильнее абстракции.
- Не использовать «ШОК», «СРОЧНО», «СЕКРЕТ», «ВЫЛЕЧИТ».
- Не обещать гарантированный результат.
- Не маркировать человека диагнозом.
- Не ставить вопросительный и восклицательный знаки одновременно.

Проверка: уменьшить обложку до ширины 10–12 см. Если смысл и лицо не читаются — упростить.

## 🧪 Протокол A/B-теста

### До публикации

Подготовить три честных варианта:

| Вариант | Что меняется | Что остаётся одинаковым |
|---|---|---|
| **A** | Формулировка проблемы | Фото, композиция, цвет |
| **B** | Фото или жест Евгения | Тема, текст, цвет |
| **C** | Композиция «лицо» vs «движение» | Обещание и заголовок |

В одном тесте менять **одну главную переменную**. Все варианты должны точно соответствовать содержанию видео.

### Запуск

1. Использовать встроенный YouTube Test & Compare, если функция доступна.
2. Не менять одновременно заголовок и обложку во время чистого теста.
3. Не делать вывод в первые часы на малом объёме данных.
4. Дать тесту завершиться по правилам платформы либо собрать достаточный сопоставимый период.
5. Зафиксировать даты, варианты, гипотезу и результат в [аналитике](./10_ANALYTICS.md).

### Решение

Победитель определяется не только CTR:

- доля времени просмотра варианта;
- CTR по источникам трафика;
- удержание первых 30 секунд;
- соответствие обещания содержанию;
- клики на страницу теста.

Если CTR вырос, а удержание первых 30 секунд заметно снизилось, обложка создала неверное ожидание — такой вариант не масштабировать.

## 🔁 Еженедельный процесс

### До съёмки

- [ ] Сформулирована одна визуальная проблема.
- [ ] Запланированы 3–5 фото-поз.
- [ ] В shot list добавлены крупный портрет, полный рост и деталь.

### До публикации

- [ ] Сделаны минимум два варианта.
- [ ] Текст каждого — 2–5 слов.
- [ ] Нет фальшивой анатомии и AI-лица.
- [ ] Обложка читается в мобильном размере.
- [ ] Заголовок и обложка дополняют друг друга.

### Через 28 дней

- [ ] Вариант и результат занесены в журнал тестов.
- [ ] Успешный паттерн добавлен в библиотеку.
- [ ] Неудачный паттерн описан вместе с причиной.
- [ ] Следующий тест меняет только одну переменную.
