# ♻️ Система переупаковки YouTube EG
> Один длинный ролик превращается в недельный контент-пакет, сохраняя одну идею и один CTA в каждой единице.

---

## 📋 Свойства

| | |
|---|---|
| **Статус** | 🟢 Рабочий стандарт |
| **Базовая единица** | Одно утверждённое длинное видео |
| **Цикл** | 7 дней |
| **Публикация** | Только после ручного OK |
| **Approval state** | `SYSTEM_APPROVED` |
| **Обновлено** | 2026-07-29 |

## 🧩 Обязательные поля пакета

`Project ID` · YouTube URL · главная мысль · CTA · календарь · статусы · ссылки · метрики · approval state.

## 📦 Минимальный пакет

- **5–10 Shorts**
- **3–5 Reels**
- **1 Telegram-пост**
- **1 VK-пост**
- **1 Community-пост**
- **1 статья на сайт**
- **1 серия Stories**
- **несколько тезисных постов**

Расширение при наличии ресурса: **email, Threads, Дзен**. Оно не блокирует обязательный пакет.

## 🗺️ Карта контента

| Производная | Роль | Источник в long-form | Один CTA | Обязательный результат |
|---|---|---|---|---|
| Shorts 1–2 | Охват | Хук / контраст | Гайд или подписка | Новая аудитория |
| Shorts 3–5 | Utility | Тест / действие | Тест тела | Практическая польза |
| Shorts 6–10 | Authority/Proof | Механизм / кейс | Релевантный продукт | Доверие |
| Reels 1–3 | Охват и доверие | Сильные самостоятельные тезисы | Директ / гайд | Вход в воронку |
| Reels 4–5 | Offer Bridge | Путь и следующий шаг | Один продукт | Заявка |
| Telegram | Глубина | Главный механизм | Один следующий шаг | Прогрев |
| VK | Адаптированная польза | Механизм + локальный контекст | Один следующий шаг | Доверие / запись |
| Community | Диалог | Вопрос / выбор / тезис | Комментарий | Исследование аудитории |
| Stories | Дожим | Закулисье → мысль → CTA | Один CTA | Переход |
| Статья | Поиск | Полный разбор | Релевантный продукт | Evergreen-трафик |
| Тезисные посты | Частота | 3–7 выводов | По контексту | Повторные касания |

## 📅 Календарь на 7 дней

| День | Основной выпуск | Поддержка | Контроль |
|---|---|---|---|
| **1** | Long-form YouTube | TG/VK draft через 5–10 минут после OK; Stories | Ссылки и первые комментарии |
| **2** | Shorts 1 + Reels 1 | Community-вопрос | Удержание хука |
| **3** | Shorts 2 | Тезисный пост 1 + Stories | Сохранения / ответы |
| **4** | Shorts 3 + Reels 2 | Telegram deep-dive | Клики CTA |
| **5** | Shorts 4 | VK-адаптация + Stories | Досмотры |
| **6** | Shorts 5 + Reels 3 | Статья на сайт | Поиск / время чтения |
| **7** | Лучший дополнительный клип | Тезисы 2–3; email/Threads/Дзен опционально | Недельный разбор |

Оставшиеся Shorts/Reels распределять на следующие 1–3 недели, чтобы long-form продолжал работать.

## 🔄 Производственный цикл

1. Разметить в расшифровке самостоятельные смысловые фрагменты.
2. Для каждого назначить функцию: `Authority | Utility | Proof | Offer Bridge`.
3. Сформулировать отдельный хук; не начинать клип с середины мысли.
4. Сохранить исходный смысл и ограничения.
5. Подобрать один CTA по теме.
6. Адаптировать язык и длину под канал, не делать механический copy-paste.
7. Проверить captions, safe zones, ссылки и права.
8. Получить ручное approval.
9. Публиковать по календарю и записывать URL/метрики.

**STOP-GATE 1:** производная не готова, если без контекста искажает исходную мысль.

**STOP-GATE 2:** социальная публикация запрещена без `APPROVED_BY_EG`.

## ✅ QA пакета

- [ ] У каждого материала одна главная идея.
- [ ] У каждого материала один CTA.
- [ ] Shorts/Reels имеют самостоятельный хук и завершение.
- [ ] TG и VK адаптированы под канал.
- [ ] Статья не является сырой расшифровкой.
- [ ] Нет новых неподтверждённых утверждений.
- [ ] Ссылки проверены по `products.yaml`.
- [ ] Все статусы, URL и даты записаны в `07_DISTRIBUTION.md`.
- [ ] Есть минимум один Authority, Utility, Proof и Offer Bridge материал.
- [ ] Расширенный пакет не мешает обязательному минимуму.

## 📊 Недельный разбор

Сравнивать не только просмотры:
- удержание первых 3/30 секунд;
- досмотры и сохранения;
- комментарии и ответы;
- переходы по CTA;
- заявки / покупки;
- темы, которые стоит развить в следующий long-form.
