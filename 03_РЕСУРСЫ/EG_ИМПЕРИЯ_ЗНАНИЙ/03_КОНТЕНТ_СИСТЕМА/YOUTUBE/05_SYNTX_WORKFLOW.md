## 🎯 Для чего использовать

| Подходит | Не подходит |
|---|---|
| Анатомические миниатюры | Полный авто-монтаж длинного видео |
| Визуализация опоры, дыхания, координации | Замена лица и голоса Евгения |
| Предметные метафоры | Диагнозы и «доказательство лечения» |
| Простые диаграммы и stills | Случайный красивый B-roll |
| Macro текстур 2–5 секунд | Сцены, не связанные с точной фразой |

## 🎨 Визуальный язык EG

Тёмный графит, анатомические миниатюры, кость и матовые фактуры, серебряная нить, реальные мужские руки, мягкий боковой свет, macro, малая глубина резкости, деликатное плёночное зерно.

**Исключить:** neon, cartoon, horror, gore, перегрузку деталями, футуристическую клинику, дешёвый fitness look, ложную медицинскую точность.

## 🔄 Ручной цикл в браузере

1. Выбрать точную фразу из монтажного брифа.
2. Заполнить сцену в `PROJECTS/_TEMPLATE/05_SYNTX_PROMPTS.md`.
3. Создать low-resolution test с минимальным расходом кредитов.
4. Оценить смысл, анатомическую корректность, композицию и читаемость.
5. Выбрать один результат; не масштабировать слабый тест.
6. Запустить upscale/final только для утверждённого варианта.
7. Экспортировать оригинальный файл без пересжатия.
8. Поместить в `05_ASSETS/AI/`.
9. Записать модель, настройки, расход кредитов и имя файла в карточке проекта.

**STOP-GATE 1:** генерация не запускается без goal, duration, точной реплики и negative prompt.

**STOP-GATE 2:** upscale не запускается без визуального approve.

## 🧪 Контроль результата

- [ ] Сцена объясняет точную фразу.
- [ ] Длительность 2–5 секунд достаточна.
- [ ] Нет анатомических искажений, лишних пальцев и невозможной механики.
- [ ] Нет медицинского обещания или псевдодиагностики.
- [ ] Визуал соответствует тёмному натуральному стилю EG.
- [ ] Нет узнаваемого копирования чужой сцены, лица или брендинга.
- [ ] Кадр сохраняет место под титр, если он нужен.
- [ ] Движение не мерцает и не отвлекает от голоса.
- [ ] Лицензия коммерческого использования проверена.
- [ ] Модель, settings, credits и filename записаны.
