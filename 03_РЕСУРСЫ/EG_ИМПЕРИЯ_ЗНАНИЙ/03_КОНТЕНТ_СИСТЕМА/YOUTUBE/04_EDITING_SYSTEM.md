## 🎯 Результат

Готовое видео должно быть ясным без визуального шума, сохранять живую экспертную подачу и вести к одному релевантному следующему шагу.

**Целевая пропорция:**
- реальные кадры Евгения: **75–90%**;
- AI-вставки, схемы и иллюстрации: **10–25% максимум**;
- одна вставка — одна конкретная фраза, которую она поясняет.

> ⚠️ AI не заменяет экспертное присутствие и не используется как декоративный фон.

Для первого пилота использовать **DaVinci Resolve** как единый master timeline: монтаж, звук, цвет и субтитры. CapCut Desktop подходит для срочных вертикальных адаптаций и быстрого старта. Remotion подключать после 4–6 выпусков, когда главы, счётчики и CTA стабилизированы.

## 🔄 Монтажный цикл

### 1. Приёмка
- [ ] Исходники скопированы минимум в два места.
- [ ] Частота кадров и разрешение зафиксированы.
- [ ] Пики звука не клиппируют.
- [ ] Созданы proxy для тяжёлых 4K-файлов.
- [ ] Есть сценарий, расшифровка и `04_EDITING_BRIEF.md`.

**STOP-GATE 1:** монтаж не начинается, если нет полного звука, исходников или понятного тезиса.

### 2. Черновая сборка
1. Собрать сильный хук без заставки «для разгона».
2. Удалить технические паузы, дубли и смысловые повторы.
3. Сохранить естественное дыхание речи.
4. Выстроить: проблема → механизм → решение → следующий шаг.
5. Зафиксировать selects и ориентировочные тайм-коды.

### 3. Чистовой монтаж
- Основа — спокойный документальный ритм.
- Резать по смыслу, реакции, движению или смене аргумента.
- Использовать J-cut/L-cut, когда звук следующего или предыдущего кадра делает переход естественнее.
- Не применять случайные zoom, glitch, shake, вспышки и переходы «ради динамики».
- Возвращаться к лицу Евгения как к смысловому якорю.
- Экранный текст сокращать до тезиса; не дублировать всю речь.

### 3.1 Монтажный профиль EG по референсу BIOMACHINE

Принципы брать, идентичность не копировать.

| Параметр | Стандарт EG |
|---|---|
| **Темп** | 10–15 секунд на кадр; внутри упражнения не резать без причины |
| **Доля кадров** | 70–80% демонстрация · 10–15% talking head · 5–10% схемы/титры · 0–5% AI |
| **Заставка** | 0–8 секунд максимум; сразу ценность |
| **Удержание** | Новизна каждые 45–90 секунд через смену упражнения, ракурса или cue |
| **Титры** | Крупнее мобильного минимума; тёмная подложка; не закрывать суставы |
| **Музыка** | Тихий ambient или без музыки; голос первичен |
| **CTA** | Один раз нативно в конце + описание/закреп; без крика «подпишись» внутри практики |

Для CapCut-пилота: сначала вырезать рискованные claims, поставить главы `1/6–6/6`, автосубтитры с ручной правкой, затем новый финал с тестом.

### 4. Вставки

Вставка разрешена, если она:
1. объясняет точное предложение;
2. показывает движение, объект, схему или контекст;
3. сокращает путь к пониманию;
4. не создаёт ложной анатомической или медицинской уверенности.

Приоритет: реальные демонстрации → собственные схемы → лицензированный материал → AI-визуал.

### 5. Звук и цвет
- Разборчивость голоса важнее музыки и эффектов.
- Убрать устойчивый шум без металлических артефактов.
- Выровнять громкость между фрагментами.
- Музыка не конкурирует с речью; ducking — мягкий.
- Цвет кожи естественный; камеры согласованы по балансу белого, контрасту и насыщенности.
- Единый look на всём ролике, без «кислотного» cyan.

### 6. Субтитры и графика
- Короткие строки, высокая контрастность, безопасные поля.
- Не закрывать лицо, стопы, суставы и важные детали движения.
- Выделять максимум одно ключевое слово.
- Проверить имена, термины, числа и CTA вручную.

## 📦 Профили экспорта

| Профиль | Разрешение | Контейнер | Видео | Аудио |
|---|---:|---|---|---|
| **YouTube 4K** | 3840×2160 | MP4 | H.264/H.265, высокий bitrate | AAC, 48 kHz |
| **YouTube 1080p** | 1920×1080 | MP4 | H.264, высокий bitrate | AAC, 48 kHz |

Экспортировать progressive, с исходной частотой кадров. После экспорта просмотреть файл вне монтажной программы.

## ✅ QA перед утверждением

- [ ] Хук понятен в первые 15 секунд.
- [ ] Одна главная мысль удерживается до конца.
- [ ] Нет смысловых дублей, оборванных слов и случайных jump cut.
- [ ] Реальные кадры занимают 75–90%.
- [ ] Каждая AI-вставка привязана к точной фразе.
- [ ] Голос разборчив на телефоне и в наушниках.
- [ ] Музыка не маскирует речь.
- [ ] Цвет и кожа стабильны.
- [ ] Субтитры вычитаны вручную.
- [ ] Утверждения о здоровье корректны и без обещаний результата.
- [ ] CTA один и соответствует теме.
- [ ] Ссылки и написание продуктов сверены с `products.yaml`.
- [ ] 4K/1080p-файл открывается и воспроизводится полностью.
- [ ] Исходники, project file, шрифты и assets сохранены.

**STOP-GATE 2:** файл не передаётся в публикацию без статуса `APPROVED_BY_EG`.

## 🤝 Передача монтажёру

Передать одним пакетом:
- [ ] сценарий и утверждённую расшифровку;
- [ ] selects / EDL;
- [ ] заполненный `PROJECTS/_TEMPLATE/04_EDITING_BRIEF.md`;
- [ ] shot list и папку assets;
- [ ] AI-промты с выбранными результатами;
- [ ] референсы только по ритму и логике;
- [ ] брендовые шрифты, цвета и правила субтитров;
- [ ] дедлайн черновика, число раундов правок и профиль экспорта.

Формат обратной связи: `тайм-код → что не работает → требуемое изменение`. Комментарий «сделать динамичнее» без конкретики не использовать.
