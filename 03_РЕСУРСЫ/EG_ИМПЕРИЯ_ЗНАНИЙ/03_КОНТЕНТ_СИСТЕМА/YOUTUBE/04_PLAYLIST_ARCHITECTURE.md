## 🧭 Принципы

1. **Один плейлист — одна задача.** Утренние зарядки не смешивать с вечерними. Разборы не смешивать с follow-along.
2. **Не создавать пустые публичные.** Черновик в Studio допустим как private/unlisted до первого ролика.
3. **Максимум 2 плейлиста на видео.** Один основной + один дополнительный только при реальной смысловой связи.
4. **Сначала практика, потом библиотека.** «Начните отсюда» открываем, когда есть 5–7 сильных базовых роликов.
5. **Утро и вечер рядом.** На главной оба плейлиста живут в секции «Практики на каждый день».

> 💡 **Порядок роста:** сейчас публично открываем только «Утренние зарядки». Остальное — по первому релевантному видео.

## 🏠 Как показывать на главной

Секция **«Практики на каждый день»** (утро и вечер рядом):

1. Утренние зарядки \| 5–15 минут  
2. Вечерние комплексы \| расслабление и восстановление *(когда станет публичным)*

Полный порядок главной: [Упаковка канала](./01_CHANNEL_PACKAGING.md).

## 🎯 Как выбирать плейлист для нового видео

| Тип ролика | Основной плейлист | Второй (опционально) |
|---|---|---|
| Утренняя зарядка 5–15 мин | Утренние зарядки | Мобильность и суставы — только если акцент на конкретном суставе |
| Вечерний комплекс | Вечерние комплексы | Дыхание / восстановление — если ядро выпуска про регуляцию |
| Follow-along всего тела | Тренировки всего тела | Домашние \| Без тренажёров — если ядро = дом/минимум места |
| Домашняя тренировка BW / free equipment | Домашние \| Без тренажёров | Тренировки всего тела — если это полноценный full-body |
| Улица / outdoor | Тренировки на улице | — |
| Гири / свободный инвентарь (фокус) | Гири и свободный инвентарь | Тренировки всего тела — если full-body |
| Экспертный разбор механизма | Биомеханика: разборы | — |
| Дыхание / осанка / soft recovery | Дыхание, осанка, восстановление | — |
| Короткий учебный клип «как делать X» | Библиотека упражнений | — |
| Базовый маршрутный выпуск | Начните отсюда | Тематический плейлист по смыслу |

> ⚠️ Если сомневаешься — оставляй **один** основной плейлист. Второй не добавлять «на всякий случай».

## ❌ Ошибки

- один общий плейлист «все видео»;
- 15 узких пустых публичных плейлистов;
- утро + вечер в одном списке;
- одно видео сразу в 3–4 плейлистах;
- ссылки на `eg.egoshev.ru`.

## ✅ Чек-лист перед созданием плейлиста в Studio

- [ ] Есть минимум одно готовое видео под эту задачу.
- [ ] Название и описание скопированы из карточки `PLAYLISTS/`.
- [ ] Плейлист не дублирует уже существующую публичную серию.
- [ ] На главной канале есть место (или план секции).
- [ ] В описании плейлиста нет `eg.egoshev.ru`.
