# Как устроен перенос сайта (простыми словами)

> Решение на сейчас: работаем с **Next.js** (уже на сервере + GitHub `IVANFROL/egoshev.ru`).  
> WordPress учителя — ок как идея «удобная админка», но **с нуля отложит** блог и Дзен на недели.  
> Сначала: тест `eg.egoshev.ru` → публикации → Дзен/RSS → потом DNS на основной домен.

---

## Три копии сайта

```
1) Tilda (egoshev.ru для людей сейчас)
      ↓ IT уже скопировал вид/контент
2) GitHub — код Next.js (источник правды для разработки)
      ↓ выкладка на сервер
3) Timeweb VPS — сайт крутится (сейчас открывается как eg.egoshev.ru по HTTP)
```

**Перенести сайт** = не «нажать одну кнопку», а:
1. Код на сервере (уже есть)  
2. Проверить тест-адрес  
3. Починить блог/админку  
4. SSL (замочек https)  
5. Когда всё ок — в REG.RU поменять DNS основного домена  

Пока DNS `egoshev.ru` смотрит на Tilda — **люди не пострадают**.
