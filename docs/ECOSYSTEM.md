## Суть

Не «тренер с ботом», а воронка: **внимание → доверие → диагностика → продукт → удержание**.

| Слой | Роль |
|------|------|
| Instagram `@egoshev1` | Новый трафик |
| Сайт `egoshev.ru` (Tilda) | Центр маршрутов + SEO |
| Публичный канал `@EvgeniiGoshev` | Прогрев (посты после approve) |
| Telegram-бот | Автоматизация: гайд, оплаты, клуб-доступ, тест |
| Закрытый клуб | Ты ведёшь; бот только доступ |
| Prodamus | Оплата и подписка |
| Timeweb | Бот, webhook, БД, cron |
| Tilda Members + Kinescope | Уроки курса |

## Два главных пути

### Путь 1 — Личная работа (Москва)
Instagram / Яндекс Карты / Telegram → сайт → «Записаться» → анкета → ты/админ → студия.

### Путь 2 — Онлайн
Instagram / Telegram / сайт → гайд или тест → тест 684 ₽ → план → курс / клуб / консультация.

## Принципы

1. Цены и названия — только из `products.yaml`.
2. Не ставить медобещания и диагнозы.
3. Тест v1 — ручной разбор; v2 — скоринг + ручная правка.
4. Клуб: бот = доступ; контент = человек.
5. Канал: черновик → approve → публикация.
6. **Гибрид:** Tilda = продукты/продажи (`egoshev.ru`); Timeweb = блог (`blog.egoshev.ru`) + бот (`bot.egoshev.ru`).

7. Секреты не в git и не в чатах.
