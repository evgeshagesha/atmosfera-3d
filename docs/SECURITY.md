# SECURITY — безопасность

---

## Секреты

- Хранить в `.env` на сервере / локально  
- **Не** коммитить в git  
- **Не** присылать токены в чат Cursor  
- Ротация при утечке  

Список: см. [ENVIRONMENT.md](./ENVIRONMENT.md).

---

## Webhook Prodamus

- Проверка подписи (secret)  
- HTTPS only  
- Идемпотентность по order_id  
- Логирование без утечки карт (их и нет — Prodamus)

## Telegram

- Бот-админ канала/клуба — минимальные права  
- Admin approve только для whitelist `ADMIN_TELEGRAM_IDS`  
- Не логировать лишние ПДн

## Персональные данные
