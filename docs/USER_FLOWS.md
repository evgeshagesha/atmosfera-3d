# USER_FLOWS — маршруты пользователя

---

## 1. Из Instagram

1. Reels / Stories с кодовым словом **ТЕЛО** или ссылкой `t.me/БОТ?start=telo`.
2. Бот: приветствие → выдача гайда + зарядки → предложение канала.
3. Оффер теста 684 ₽.
4. Источник фиксируется: `utm` / deep link `telo`.

**Легально:** ссылка в шапке/Stories, ManyChat/официальный API.  
**Запрещено:** серый скрейпинг DM, пароли Instagram.

---

## 2. Из Telegram (канал)

1. Пост/PDF (после approve) с CTA.
2. Кнопка → бот (`start=test` / `start=club` / `start=kurs`) или сайт.
3. Оплата → выдача / доступ.

---

## 3. С сайта egoshev.ru

### CTA «Записаться на личный приём»
Анкета → заявка → уведомление → связь → студия.

### CTA «Онлайн от 684 ₽»
Блок продуктов → тест / 1990 / 9990 / клуб / персоналка.

Каждая карточка: название, результат, цена, кнопка, UTM, событие аналитики.

---

## 4. Из Яндекс Карт

Локальный спрос → сайт / запись → анкета → студия. UTM: `yandex_maps`.

## 6. В клуб

Оплата подписки → webhook → invite → статус `/status`.  
При неоплате: льготный период → ограничение доступа → восстановление после оплаты.
