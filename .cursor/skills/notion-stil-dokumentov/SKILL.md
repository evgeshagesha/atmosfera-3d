# Навык: стиль Notion для документов

Когда создаёшь или обновляешь `.md` файлы в этом проекте, используй этот шаблон.

## Структура страницы

1. **Заголовок** с emoji-иконкой: `# 🎯 Название страницы`
2. **Callout-описание:** `> Кратко, зачем эта страница.`
3. **Разделитель:** `---`
4. **Блок «Свойства»** — таблица 2 колонки (поле | значение)
5. **Основной контент** — секции с emoji в `##`
6. **Callout-подсказки:** `> 💡 **Подсказка:** ...` или `> ⚠️ **Важно:** ...`
7. **Навигация внизу:** `[← Главная](../НАЧНИ_ЗДЕСЬ.md)`

## Правила оформления
- Короткие абзацы, много воздуха между блоками
- Таблицы вместо длинных списков там, где уместно
- Чеклисты `- [ ]` для задач
- Ссылки на другие страницы системы
- Язык: только русский
- Не перегружать emoji — одна иконка на секцию

## Пример блока «Свойства»

```markdown
## 📋 Свойства

| | |
|---|---|
| **Статус** | 🟢 Активно |
| **Ответственный** | Евгений |
| **Обновлено** | дата |
```
