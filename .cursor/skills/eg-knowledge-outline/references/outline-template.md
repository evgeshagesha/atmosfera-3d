# Outline template — 4 формата

> Notion-ish RU. Плейсхолдеры `[...]` — не копировать корпус vault.

## Общие свойства (все форматы)

| | |
|---|---|
| **Тема** | `[...]` |
| **Формат** | урок / вебинар / модуль / доклад |
| **Длительность** | `[...]` |
| **Аудитория** | `[...]` |
| **Источники vault** | `[пути…]` |
| **Следующий продукт** | `[гайд / тест / курс / клуб / консультация / офлайн]` |

---

## 1. Урок / план занятия

1. **Цель** — `[что изменится в функции / ощущении / контроле]`
2. **Разогрев / регуляция** — `[дыхание / мягкая мобилизация / …]`
3. **Основная практика** — `[паттерн / упражнение / протокол]`
4. **Интеграция** — `[в походку / быт / спорт]`
5. **Домашнее** — `[1–3 коротких действия]`
6. **CTA** — `[следующий шаг продукта]`

> 💡 Один главный навык на урок. Не перегружать блоками.

---

## 2. Вебинар

1. **Хук 30–60 с** — `[контраст / наблюдение / вопрос]`
2. **Проблема** — `[что происходит у аудитории]`
3. **Механизм** — `[почему так, без диагноза-ярлыка]`
4. **Демо / практика** — `[1 живая практика]`
5. **Q&A** — `[типовые вопросы]`
6. **Оффер / следующий шаг** — `[мягкий, ясный CTA]`

---

## 3. Онлайн-модуль

1. **Outcomes** — `[3–5 измеримых результатов модуля]`
2. **Блоки** — `[блок 1 → … → блок N]`
3. **Практика** — `[домашние / чек-листы]`
4. **Ретест** — `[как проверить прогресс]`
5. **Апсейл** — `[куда вести после модуля]`

---

## 4. Конференционный доклад

1. **Тезис** — `[одна сильная мысль]`
2. **Три акта** — `[контекст → механизм → путь]`
3. **Одна практика** — `[демо / разбор на сцене]`
4. **Takeaway** — `[что унести слушателю]`
5. **Мягкий бренд-мост** — `[Атмосфера 3D / EG без жёсткой продажи]`
