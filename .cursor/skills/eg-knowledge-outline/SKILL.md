# eg-knowledge-outline

Скилл для outline из vault знаний EG. Не копирует корпус — тянет только релевантные фрагменты.

## Роль

Из `03_РЕСУРСЫ/EG_ИМПЕРИЯ_ЗНАНИЙ/` собрать **структурированный план** (урок / вебинар / модуль / доклад) в тоне Атмосфера 3D / EG: спокойно, премиально, по-русски.

- Не встраивать PDF, скрины, длинные транскрипты в skill или в ответ как дамп.
- Цитировать идеи кратко; пути источников — в свойствах outline.
- Формула речи: **что происходит → почему → что делать → результат**.

## Когда применять

**Triggers:** план урока / занятия, вебинар, онлайн-урок, модуль курса, конференционный доклад, «outline из базы знаний», «из EG_ИМПЕРИЯ_ЗНАНИЙ».

**Не применять:** только Notion-оформление готового текста → `notion-stil-dokumentov`; Remotion/рендер → `remotion-*`; бот / деплой / код сайта; полный дамп vault; меддиагноз и обещания «вылечим».

## Workflow

### 1. Уточнить запрос

Тема + формат + длительность + аудитория. 1–3 вопроса **или** сильная гипотеза с пометкой «гипотеза».

### 2. Pull из vault

**Mandatory Read (перед outline по тренировочной системе / позиционированию / воронке):**

1. `03_РЕСУРСЫ/EG_ИМПЕРИЯ_ЗНАНИЙ/01_EG_OS_БРЕНД/TRAINING_SYSTEM_POSITIONING_MASTER.md`
2. `03_РЕСУРСЫ/EG_ИМПЕРИЯ_ЗНАНИЙ/01_EG_OS_БРЕНД/OWNERSHIP_MAP.md`

Outline должен выравниваться с осью «ТЕБЕ НУЖЕН ТОЛЬКО ТЫ» из MASTER (философия системы, не CTA).

По `references/vault-map.md`: матрицы (МФР, ПИР, дыхание, тесты, блок1), `01_каталоги/`, Functional Patterns, ФТ_КНИГИ, Product System.

Порядок: README/каталоги → сырьё. Только папки по теме (Glob/Read).

### 3. Собрать outline

Шаблон: `references/outline-template.md`. Notion-ish RU (emoji-секции, таблица свойств, callout). Для чистого оформления можно опереться на `notion-stil-dokumentov` **только как на стиль**, не подменяя этот skill.

### 4. Продуктовая лестница

Следующий шаг: гайд / тест / курс / клуб / консультация / офлайн. Опираться на `06_ПРОДУКТЫ_И_ШКОЛА/` (+ дайджест Product System при необходимости).

**Funnel checklist (CTA / следующий шаг):**

| Шаг | ID / URL |
|-----|----------|
| Тест | `684` — https://egoshev.ru/testik |
| База | `9990` |
| Клуб | `1758` |
| Анкета | https://egoshev.ru/anketa |

YouTube / контент-CTA — **не** `eg.egoshev.ru`.

### 5. Путь сохранения (hint)

Предложить путь под:

`03_РЕСУРСЫ/EG_ИМПЕРИЯ_ЗНАНИЙ/10_ВЫХОДЫ_ПРОДУКТОВ/{уроки|вебинары|модули_онлайн|черновики_книг}/`

**Не писать файл**, пока пользователь явно не попросит сохранить.

## Quality gate

Перед выдачей — `references/tone-bans.md`:

- запреты: медобещания, диагноз-ярлык, инфобиз-клише;
- разрешено: функция, качество движения, регуляция, гипотеза, путь, прогрессия;
- тон: спокойный премиум, не инфобиз.

## Вне скоупа

- Копирование корпуса vault в skill / references
- Telegram-бот, деплой, код сайта
- Remotion / видео-пайплайн
- Создание субагента / command / rule / hook
- Медицинский диагноз и гарантии медрезультата
