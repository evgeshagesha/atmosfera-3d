| trigger / intent | пример фразы | ответ-скелет EG | CTA | next_state / handoff | notes |
|---|---|---|---|---|---|
| цена | «Сколько стоит?» | Коротко назвать продукт и цену из `products.json`; без торга и «скидок навсегда». | Ссылка на продукт / «какой формат ближе» | dialogue → product или studio_invite | Курс 9990 · клуб 1680/мес |

| где студия | «Где вы находитесь?» | Адрес/район + как добраться; тон премиум, без длинного тура. | Карта / «записаться» | dialogue → studio_invite | Факт из ГЛАВНЫЙ_КОНТЕКСТ |
| болит X | «Болит поясница / колено» | Без диагноза: локальное ощущение часто связано с системой движения; путь — оценка → настройка. | Гайд / тест тела / анкета на приём | welcome/guide или questionnaire | FAQ ≠ диагноз |

| анкета | «Что заполнять?» | 3–5 спокойных вопросов: запрос, опыт, ограничения (без меддиагноза). | Заполнить анкету | questionnaire → dialogue | Owner: skill → KB texts |
| просто смотрю | «Пока просто смотрю» | Нормально. Дать один полезный шаг (гайд/канал), без дожима. | Канал / гайд | welcome/guide; FU 2h мягко | Не давить booking |
| после гайда | «Гайд получил» | Один блок сегодня; ясность важнее перегруза. | Канал / тест | soft_followup (fu_2h) | См. `followups.py` |
| тест тела | «Что за тест?» | 20 движений → персональный план; не диагноз, а маршрут. | Ссылка тест | soft_followup (fu_24h) | Product upsell ≠ studio |
| дыхание / осанка | «Про дыхание и осанку» | База опоры и регуляции; курс как спокойный следующий шаг. | Ссылка breath/posture | soft_followup (fu_72h) / dialogue | Тон EG, без медобещаний |

| свяжитесь | «Свяжитесь со мной» | Подтвердить: менеджер на связи; 1 уточняющий вопрос + путь к записи. | Анкета / слот | questionnaire → studio_invite | Handoff человек при необходимости |
