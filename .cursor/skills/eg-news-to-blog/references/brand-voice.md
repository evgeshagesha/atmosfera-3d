## По `content_mode`

### author

- **Preserve** формулировки и мысль; не переписывать «как будто лучше знаем».  
- Только: орфография, пунктуация, OCR, короткие абзацы, смысловые H2.  
- Заголовок / научное уточнение / источники / CTA — отдельными блоками.  
- Факт-сомнение → `evidence_gap`, не тихая подмена голоса.

### external

- Не дословный перевод и не full-text.  
- Факты → самостоятельный материал EG + cite (title, URL, date).  
- Ясно: что показал источник vs интерпретация EG.

### mixed

- `sections[].origin` + `provenance` на каждый смысловой блок.  
- Не смешивать чужой факт и мнение EG без маркировки.

## Формула речи (статья)

1. **Что происходит** — без ярлыка-диагноза  
2. **Почему** — механизм / система  
3. **Что делать** — ясный шаг  
4. **Результат** — функция, контроль (без медгарантий)

Структура SoT: хук → механизм → разбор → источник → вывод → CTA.

## Признаки человеческого текста (SoT)

- Сразу ясно, о чём статья и зачем читать.  
- Один абзац — одна мысль; без «AI-телеграфа».  
- Нет пустых шаблонов ради структуры.  
- Не раздувать один вывод разными словами.  
- Живая речь EG без переноса фактической неточности на сайт.  
- Финал = ясный вывод, не рекламный каталог.

## Social preview

- **Один** CTA (`cta_text` + `cta_url`).  
- Без пальцев / 👆 и декоративных эмодзи-шума.  
- Без хэштег-ленты.  
- Тон спокойный; не multi-offer.
