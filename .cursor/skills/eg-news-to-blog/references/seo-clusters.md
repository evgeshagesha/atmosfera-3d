## GEO / локальность

- Заголовок = поисковый запрос + угол EG.  
- 1–2 естественных якоря (студия / движение / осанка) — **без** спама «Москва» в каждой статье.  
- Локальный сигнал: автор, организация, контакты, schema, страницы услуг — не механический keyword stuffing.  
- GEO: ясные ответы, раскрытие терминов, факт ≠ мнение, первоисточник (PMID / URL).

## Правила выбора

1. Тема → ближайший кластер (не натягивать студию на чистый longevity без моста).  
2. Offer Bridge — **один** CTA (кроме явного author compact-programs запроса).  
3. Москва / запись — `studio_moscow` или явный офлайн-мост.  
4. Запреты: `tone-bans.md`.
