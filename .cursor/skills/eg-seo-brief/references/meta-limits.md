# Meta limits — eg-seo-brief

Meta title/description length + tone limits.

## Purpose

Черновики meta без stuffing и кликбейта.

## Limits

| Field | Guide |
|-------|--------|
| `meta_title` | ~50–60 chars; один главный интент |
| `meta_description` | ~140–160 chars; ясная польза + soft bridge |

## Tone

- спокойный EG · без «вылечим» / секретных методов  
- без ALLCAPS / emoji-spam  
- GEO: естественные якоря, не «Москва» в каждой фразе
